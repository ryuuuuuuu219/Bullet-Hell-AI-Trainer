教師操作、逆伝播、遺伝的アルゴリズムとの分離、保存方法を整理したもの。

「実装済み」と「Unity実行未確認」を分けて記載する。

◇ネットワーク構造

実装済み。

入力層：85
第1隠れ層：16
第2隠れ層：12
出力層：2

構造

85入力
→ tanh 第1隠れ層16
→ tanh 第2隠れ層12
→ tanh 出力2

出力0：X方向移動量
出力1：Y方向移動量

出力範囲：-1～1
低速モード：未実装
第3出力：未実装

NN出力計算はPlayerMovementController.FixedUpdateからAidata.output()を呼ぶたびに行う。
履歴の更新周期が0.2秒でも、行動出力自体はFixedUpdateごとに更新する。

◇既存入力0～71

1. 近接認識　入力0～5

同じ論理レイヤーに属する敵弾から、最も近い1発を選ぶ。

入力0：有効フラグ
入力1：相対位置X
入力2：相対位置Y
入力3：正規化距離
入力4：弾進行方向と対自機方向の内積
入力5：正規化脅威度

距離基準：150
脅威度基準：5
無検出時：6値すべて0


2. 注目センサー　入力6～40

危険度上位5発を選び、1発あたり7値を入力する。

・有効フラグ
・相対位置X
・相対位置Y
・現在距離
・最接近距離
・最接近時刻
・脅威度

候補が5発未満の場合、余った枠は0。


3. 対弾センサー　入力41～51

入力41～50：10方向の重み付き検出比率
入力51：全センサーの総密度

総密度＝総検出数 /（総検出数＋1）


4. 対レーザーセンサー　入力52～71

危険度上位2件を選び、1件あたり10値を入力する。

・有効フラグ
・発射済みフラグ
・発射地点相対X
・発射地点相対Y
・方向X
・方向Y
・符号付き線距離
・レーザー表面までの距離
・発射までの時間
・脅威度


◇脅威時間信号　入力72

実装済み。

BulletHellStageDefinitionがfloat[] threatArrivalTimesを保持する。
配列は生成時に次のように正規化する。

・負数は0へClamp
・昇順へSort
・同一時刻を許容
・nullまたは未指定は空配列

現在の既存ステージには具体的な到達時刻が設定されていないため、空配列。
各ステージへ値を設定した場合に信号が発火する。

ステージ開始時および世代更新時

stageElapsedTime＝0
CurrentThreatTimeSignal＝-1
nextThreatTimeIndex＝0

FixedUpdateごとの処理順

1. ゲーム内経過時間を加算
2. 毎秒0.1の速度で-1へ減衰
3. elapsedTime >= specifiedTimeとなった全イベントを処理
4. イベントを検出した場合は信号を1へ上書き

信号範囲：-1～1
配列末尾の時刻を過ぎた後：-1まで減衰して維持
配列のループ：未実装

元要件のテスト一覧には「開始時0」とあるが、詳細仕様の初期値-1を優先している。


◇短期履歴　入力73～84

実装済み。

各個体が次の2サンプルを個別に保持する。

currentSample：現在値
previousSample：0.2秒前履歴

各サンプルの6値

1. 自機座標X
2. 自機座標Y
3. 直前0.2秒の座標変位X
4. 直前0.2秒の座標変位Y
5. 近接センサー距離
6. 対レーザーセンサー距離

更新周期：ゲーム内時間0.2秒
一時停止中：FixedUpdateが停止するため履歴も進まない

初期化時

・現在位置からcurrentSampleを作成
・previousSampleへcurrentSampleをコピー
・両方の座標変位を0にする

0.2秒経過時

・新しいサンプルを取得
・直前サンプル位置との差から変位を計算
・previousSample＝currentSample
・currentSample＝新しいサンプル


◇履歴値の正規化

座標XY

Camera.mainのViewport座標を使用する。

左端／下端：-1
中央：0
右端／上端：1

変換式

normalizedX＝viewportX×2－1
normalizedY＝viewportY×2－1


座標変位XY

PlayerMovementController.MoveSpeedと0.2秒から最大移動距離を求める。

現在のPlayer.prefab実動値：300 Unity単位／秒
0.2秒の最大移動距離：60 Unity単位

正規化変位＝0.2秒間の実座標差 / 60

最終値を-1～1へClampする。
移動速度0の場合は変位0としてゼロ除算を防ぐ。


近接センサー距離

ProximitySensorのnormalizedDistanceを使用する。

接触に近い：0
距離150：1
無検出：1


対レーザーセンサー距離

有効な予告線／レーザーのsurfaceDistance最小値を使用する。

レーザー範囲内または表面距離0以下：0
DetectionRadius 50：1
無検出：1

符号付き線距離は履歴距離に使用しない。


◇教師操作モード

実装済み。

StageSelectの「教師モード（手動操作）」トグルで切り替える。
トグル値はStageSpawnManager.teacherModeEnabledへ引き継ぐ。
初期値：OFF

教師操作の条件

・StageSelectから引き継いだteacherModeEnabledがON
・PlayerAgent.LogicalLayer == 0

上記を両方満たす個体だけを教師個体とする。

操作

現在のマウスカーソル位置へ向かって移動する。
手動操作開始時は、カーソルを手動操作自機の位置へ移動する。

入力ベクトルは長さ1以内へClampするため、方向によって最高速度は増えない。
カーソルまでの距離が1物理フレームの最大移動量より短い場合は、
カーソルを通り越さないよう入力を弱める。
低速操作は未実装。

教師個体でもNNの順伝播はFixedUpdateごとに実行する。
実際の移動だけを手動入力で上書きし、NN予測値は教師学習とデバッグ用に保持する。

StageSelectの「教師モード（手動操作）」トグル状態をStageシーンへ引き継ぐ。
ONの場合は、設定されたAI個体群とは別に論理レイヤー0のManual Playerを1機追加する。
AI個体群は論理レイヤー1以降へ配置する。


◇教師データ

実装済み。

TeacherSample

inputs：85個のfloat
targetMovement：手動入力XY

移動適用直前のNN入力を配列コピーして保存する。
履歴や次フレームの入力更新によって、保存済み教師入力は書き換わらない。

採取間隔

移動入力あり：0.1秒
停止入力（0, 0）：0.5秒

停止も正解データとして扱うが、停止データだけが過剰にならないよう頻度を下げる。
保持上限：2048件
上限到達後：最古のデータから削除


◇逆伝播

実装済み。

教師サンプルを追加したタイミングで、そのサンプルを使用して1回オンライン学習する。

損失

loss＝(outputX－targetX)^2＋(outputY－targetY)^2

活性化関数：tanh
微分：1－activation^2

計算順

1. 順伝播して各層の活性化値を保持
2. 出力層デルタを計算
3. 更新前の重みで第2隠れ層デルタを計算
4. 更新前の重みで第1隠れ層デルタを計算
5. 全デルタ計算後に重みとバイアスを更新

更新対象

・inputToLayer1Weights
・layer1Biases
・layer1ToLayer2Weights
・layer2Biases
・layer2ToOutputWeights
・outputBiases

Inspector設定

teacherLearningRate：既定0.01
teacherSampleInterval：既定0.1秒
stationarySampleInterval：既定0.5秒
gradientClamp：既定1

NaNまたはInfinityの勾配は0として扱う。
更新後パラメータがNaNまたはInfinityになる場合は、更新前の値を維持する。


◇教師ネットワークの保存

実装済み。

既存のAiSaveDataとPlayerPrefsキーを使用する。

保存タイミング

・教師サンプル50件ごと
・世代更新時

世代更新前に教師個体のスナップショットを保持する。
教師個体を再生成するときは、保持した教師スナップショットを個体0へ再適用する。

旧72入力保存データの移行

・入力0～71に接続された既存重みを維持
・新規入力72～84に接続する重みを0で追加
・隠れ層、出力層、既存バイアスは維持
・保存データのinputNodeCountを85へ更新

72入力以外の不明なネットワーク形状は互換移行せず、従来どおり係数を初期化する。


◇遺伝的アルゴリズムとの分離

実装済み。

教師モード中のManual Playerは次から除外する。

・遺伝的アルゴリズムのランキング
・交叉用の親候補
・エリート候補

Manual Playerは自動世代更新の全滅判定には含める。
教師モード中も、設定人口と同数のAI個体をGA個体として生成する。
実際の総個体数は設定人口＋Manual Player 1機となる。
教師NNを後からAI個体の初期ネットワークに利用しても、教師操作中の生存スコアは継承しない。
