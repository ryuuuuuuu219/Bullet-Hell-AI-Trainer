現在のリポジトリを基準に整理すると、このプロジェクトはすでに「単純なニューラルネット」だけではなく、**教師あり学習と遺伝的アルゴリズムを組み合わせたハイブリッド学習**になっています。

## 現在使っている手法

| 分類     | 手法                | 現在の使われ方                                        |
| ------ | ----------------- | ---------------------------------------------- |
| NN構造   | 多層パーセプトロン（MLP）    | 入力85、隠れ層16・12、出力2の全結合ネットワーク                    |
| 推論     | 順伝播               | センサー入力からX・Y移動量を出力                              |
| 活性化関数  | `tanh`            | 全層で使用。出力を−1～1に収める                              |
| 初期化    | Xavier／Glorot系初期化 | 層の入出力数から重みの初期範囲を決定                             |
| 教師あり学習 | 誤差逆伝播             | 手動操作またはスクリプト教師の移動方向を学習                         |
| 損失関数   | 二乗誤差              | 予測XYと教師XYの差の二乗和                                |
| 最適化    | オンラインSGD相当        | 教師サンプルを受け取るたび、1件だけで即座に重みを更新                    |
| 安定化    | 勾配クリッピング          | 勾配を一定範囲に制限して発散を防止                              |
| 模倣学習   | Behavior Cloning  | 人間または回避ベクトル指示器の操作を、そのまま教師データとして模倣              |
| 進化計算   | 遺伝的アルゴリズム         | NNの重みとバイアスを遺伝子として世代更新                          |
| 選択     | トーナメント選択          | ランダムに選んだ2個体のうち高評価側を親にする                        |
| 交叉     | 一様交叉              | 重みごとに50%で親A・Bから継承                              |
| 突然変異   | ガウス突然変異           | 選ばれた係数に正規分布ノイズを加える                             |
| 保存     | エリート保存            | 上位1～2個体を変更せず次世代に残す                             |
| 多様性維持  | ランダム移民            | 毎世代2個体を完全ランダムなNNとして投入                          |
| 評価     | 重み付き適応度           | 与ダメージ、生存時間、画面端滞在、中心距離を合成                       |
| モデル選択  | 評価軸別保存            | 総合点とは別に、指定評価軸で保存個体を選択可能                        |
| 時系列表現  | フレームスタッキング        | 現在と0.2秒前の座標・変位・脅威距離を入力                         |
| 特徴量設計  | Attention Sensor  | 危険度や距離から注目すべき弾を選別。ただしTransformerのAttentionとは別物 |
| カリキュラム | 段階別課題             | BasicからFinalまで難度別ステージを用意。ただし自動進級型ではない          |

現在の学習を一言で表すなら、

> センサー特徴量を入力するMLPを、オンライン模倣学習と遺伝的アルゴリズムの両方で更新する方式

です。

## 実装はあるが、十分には利用されていないもの

### 教師サンプルの再利用

最大2048件の`teacherSamples`を保持していますが、現在は追加されたサンプルをその場で一度学習するだけです。蓄積したサンプルをランダムに取り出して再学習する、いわゆる**経験再生**にはなっていません。

そのため現状では、

* 最近の操作に引っ張られやすい
* 一度しか現れなかった重要場面を忘れやすい
* サンプルを保存するメモリが学習に十分還元されていない

という状態です。

### 学習損失の利用

教師損失は計算・表示されていますが、

* 移動平均
* ステージ別比較
* 検証データでの損失
* 学習率の自動調整
* 学習停止判定

にはまだ利用されていません。

### 時系列入力

過去情報を入力へ並べるフレームスタッキングは使っていますが、ネットワーク自身が内部状態を持つわけではありません。したがって「過去2時点から速度傾向を読む」ことはできますが、長期的な弾幕周期を記憶する能力は限定的です。

## 未使用だが、現在の構造へ導入しやすい手法

### 優先度が高いもの

| 手法              | 効果                     | 現プロジェクトとの相性 |
| --------------- | ---------------------- | ----------- |
| ミニバッチ学習         | 複数サンプルの平均勾配で更新を安定化     | 非常に高い       |
| 経験再生            | 過去の教師サンプルを繰り返し学習       | 非常に高い       |
| サンプルのシャッフル      | 学習順序への依存を減らす           | 非常に高い       |
| Adam            | 学習率をパラメータごとに調整         | 高い          |
| 検証用データ分離        | 学習ではなく暗記していないか確認       | 高い          |
| 左右・上下反転によるデータ拡張 | 弾幕の対称性を利用して教師データを増やす   | 高い          |
| DAgger          | AI自身が訪れた危険状態に教師が正解を付ける | 高い          |
| 優先度付き再生         | 衝突直前や誤差の大きい場面を重点学習     | 高い          |

特に最初に導入するなら、**経験再生＋ミニバッチ＋シャッフル**が適しています。現在保持している2048サンプルをそのまま活用でき、大きな設計変更も必要ありません。

### 時系列認識を強くする手法

| 手法          | 特徴                   | 用途               |
| ----------- | -------------------- | ---------------- |
| 履歴入力の延長     | 0.2秒前だけでなく複数時点を並べる   | 最も簡単             |
| 1D畳み込み・TCN  | 一定期間の入力変化から局所パターンを検出 | 周期弾幕や予告動作        |
| GRU         | 過去の重要情報を内部状態として保持    | 比較的軽量            |
| LSTM        | GRUより複雑だが長期記憶に強い     | 長周期の弾幕           |
| Transformer | 長い時系列の関係を扱える         | 現状規模では重すぎる可能性が高い |

このゲームではまず履歴を3～5時点へ増やし、それでも不足する場合にGRUを検討する順序が無難です。

### 遺伝的アルゴリズムを改善する手法

| 手法             | 現方式との差                         |
| -------------- | ------------------------------ |
| 適応的突然変異率       | 停滞したら突然変異を強め、改善中は弱める           |
| ランク選択          | 得点差が極端でも選択が偏りすぎない              |
| ルーレット選択        | 適応度に比例して親を選ぶ                   |
| 多目的最適化         | 生存・DPS・中央維持を単一得点へ潰さず別々に評価      |
| Novelty Search | 得点だけでなく「今までと異なる動き」を評価          |
| CMA-ES         | 係数ノイズの方向や大きさ自体を学習              |
| NEAT           | 重みだけでなくノード数や接続構造も進化            |
| Speciation     | 類似個体をグループ化し、珍しい戦略が即座に淘汰されるのを防ぐ |

現在の課題は「同じような回避方法への収束」が起こりやすい構造なので、将来的には**Novelty Search**か**多目的最適化**が有力です。NEATはゲームとしてネットワーク構造の進化も見せたい場合には面白い一方、実装と可視化が大幅に複雑になります。

## 強化学習として導入可能なもの

現在は、行動後の報酬から勾配を計算する本来の強化学習は使っていません。評価値は遺伝的アルゴリズムの個体選択に使われています。

導入候補は次のとおりです。

| 手法        | 適性                                   |
| --------- | ------------------------------------ |
| PPO       | 連続XY移動に対応しやすく、比較的安定。最有力              |
| SAC       | 連続操作と探索に強いが、実装・調整はPPOより複雑            |
| DDPG／TD3  | 連続操作向け。TD3の方が安定しやすい                  |
| DQN       | 行動を上下左右などに離散化するなら可能。現在の連続XY出力とは相性が悪い |
| 強化学習＋模倣学習 | 教師操作で初期学習し、その後PPOなどで自己改善する           |

ただし、このゲームでは「ユーザーが入力や評価軸を組み替えてAIを育てる」という体験自体が重要なので、PPOへ全面移行すると遺伝的アルゴリズムの観察性が薄れる可能性があります。導入するなら別モードか、教師あり学習後の微調整として扱うのが合います。

## 現時点での推奨順序

1. 保持中の教師サンプルを使った経験再生
2. 16～64件程度のミニバッチ学習
3. 衝突直前・損失の大きいサンプルを優先する仕組み
4. 左右・上下反転によるデータ拡張
5. 教師あり損失と実戦成績を分けた検証表示
6. 遺伝的アルゴリズムへの適応的突然変異
7. 必要ならGRU、または履歴入力の増加
8. 実験モードとしてPPOや多目的進化

いちばん大きな未活用資源は、すでに保存している2048件の教師サンプルです。まずここを経験再生へつなぐだけでも、現在のオンライン1件学習より学習効率と安定性がかなり改善する可能性があります。
