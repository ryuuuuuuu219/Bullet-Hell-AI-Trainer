手動操作によるニューラルネットワーク教育方法
確認日：2026-08-31


◇このメモの目的

個体ID 0を人間が操作し、その操作を教師データとしてNNへ学習させる手順をまとめる。

ネットワーク構造、85入力の詳細、逆伝播式については
「memo/NN仕様_現状.txt」を参照する。


◇教師操作

・論理個体IDは0
・StageSelectの「教師モード（手動操作）」トグルがONのときだけ有効
・手動入力を正解として個体0自身のNNを逆伝播で更新する
・GAの成績、親候補、エリート候補、全滅判定から除外される
・トグル状態はStageシーンへ引き継がれる
・別個体のManual Playerは追加しない


◇教育前の設定

1. populationSettingの個体数を2以上にする。

個体0は教師モード中にGAから除外される。
個体数1の場合、GAへ参加するAI個体が0になり、通常の世代更新が成立しない。

推奨開始値

・総個体数：5
・教師個体：個体0の1機
・GA評価個体：個体1～4の4機

◇教育の開始

1. StageSelectシーンから課題を選ぶ。

2. Startボタン左の「教師モード（手動操作）」をONにする。

3. StartボタンでStageを開始する。

4. トグル状態がStageへ引き継がれ、個体0が教師操作個体として生成される。

   教師モード中は論理レイヤー0が固定表示される。
   論理レイヤー1以降の自機、敵弾、レーザー、自機弾は描画されない。
   当たり判定やAI処理は継続し、表示だけが隠れる。

5. マウスを動かして回避操作を行う。

自機は現在のマウスカーソル位置へ向かって移動する。
ステージ開始時、マウスカーソルは手動操作自機の位置へ移動する。

移動方向は長さ1以内へ正規化されるため、斜め方向だけ移動速度が速くなることはない。
カーソルが自機に近い場合は移動量を弱め、カーソル位置を通り越さないようにする。
低速移動キーはない。


◇教育中に内部で行われる処理

FixedUpdateごとに次の順序で処理する。

1. 現在のセンサー値、脅威時間、履歴から85入力を作る。

2. 教師個体のNNでXY移動を予測する。

3. 実際の移動にはNN予測を使わず、マウスカーソルへ向かう移動入力を使う。

4. 移動適用直前の85入力をコピーする。

5. その時点の手動入力XYを正解データとする。

6. 採取間隔へ到達していればTeacherSampleを追加する。

7. 追加したサンプルで個体0自身のNNを1回逆伝播する。

教師データ

入力：85個のfloat
正解：手動入力X、手動入力Y

手を離した停止入力（0, 0）も正解として学習する。


◇教師データの採取頻度

移動入力あり：0.1秒ごと
停止入力（0, 0）：0.5秒ごと
メモリ上の保持上限：2048件

停止中のデータ採取頻度を下げ、停止データだけが大量に蓄積することを防いでいる。

2048件を超えた場合は最古のサンプルから削除する。


◇操作時の考え方

教師入力は「その場面でどちらへ動くべきか」の正解になる。

教育時は次を意識する。

・危険が来る前から、回避したい方向へ入力する
・画面端へ張り付く操作ばかりに偏らせない
・左右だけでなく上下方向の回避例も与える
・安全な場面では、必要に応じて停止入力も与える
・同じ課題だけでなく、異なる弾幕でも操作例を与える

マウスを急激に往復させる操作が多い場合、似た入力状態へ異なる正解が混在し、学習が安定しにくくなる。


◇Inspectorで確認する情報

実行中の教師個体0を選択し、Aidataコンポーネントを見る。

確認項目

・Debug Threat Time Signal
・Debug Current Sample
・Debug Previous Sample
・Debug Manual Input
・Debug Prediction
・Debug Teacher Loss
・Debug Teacher Sample Count

Debug Manual Input

現在の人間操作。

Debug Prediction

同じ場面でNNが出した移動予測。
教師モード中の実移動には使用されない。

Debug Teacher Loss

直近に採取した教師サンプルに対する、学習前の二乗誤差。
オンライン学習では入力場面が毎回変わるため、実プレイ中のLossが毎回単調減少するとは限らない。

Debug Teacher Sample Count

現在メモリ上に保持している教師サンプル数。
最大2048。


◇学習率の調整

AidataコンポーネントのTeacher Learning Rateで変更する。

既定値：0.01

Lossが激しく振動する、操作と逆方向へ予測が飛ぶ場合

・学習率を小さくする
・例：0.01 → 0.005 → 0.001

学習がほとんど進まない場合

・急に大きくせず、少しずつ増やす
・例：0.001 → 0.003 → 0.005

勾配はGradient Clampで制限される。
既定値は1。


◇教師NNの保存

保存形式：既存AiSaveData
保存先：既存PlayerPrefsキー

自動保存タイミング

・教師サンプル50件ごと
・世代更新時

世代更新時は、個体0の学習済みNNをスナップショットとして保持してから個体を再生成する。
再生成された教師個体0へ、保持したスナップショットを再適用する。

教育開始直後に終了すると50件へ到達していない可能性がある。
確実に自動保存させる場合は、Debug Teacher Sample Countを確認し、50件以上収集するか世代更新まで続ける。


◇教師NNをAI自身に評価させる方法

人間操作中の生存スコアは、教師NNのAI性能評価には使用しない。

評価手順

1. 教師データを十分に収集し、自動保存を確認する。

2. Play Modeを終了する。

3. StageSelectで「教師モード（手動操作）」をOFFにする。

4. 再びStageを開始する。

5. 個体0を含む全個体がNN出力で移動していることを確認する。

6. AI自身の操作による生存時間、与ダメージ、画面端滞在などで評価する。

保存済み教師NNをGAの初期ネットワークとして利用した場合でも、
教師操作中のスコアは引き継がず、AI自身に操作させた新しい成績だけを使用する。


◇世代更新との関係

教師モードONの場合

・個体0は全滅判定から除外
・個体0はランキングから除外
・個体0は交叉用の親候補から除外
・個体0はエリート候補から除外
・個体1以降の全AIが被弾すると、自動世代更新条件を満たす
・教師個体が生存していても世代更新できる

教師個体は世代更新で再生成されるが、NNスナップショットは引き継ぐ。


◇終了時の注意

教育終了後もStageSelectの教師モードトグルがONのままだと、個体0は引き続き人間操作になる。

通常のGA評価へ戻す場合は、StageSelectで教師モードをOFFにする。
教師モードをOFFにしてStageを開始すると、論理レイヤー0の固定表示も解除される。
