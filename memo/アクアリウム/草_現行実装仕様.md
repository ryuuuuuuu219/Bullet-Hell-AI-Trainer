| 項目 | 現行値 |

| フィールド幅 | 10,000 × 10,000 U |
| セル幅 | 100 U |
| セル数 | 100 × 100＝10,000 |
| 座標範囲 | 各軸とも −5000以上、5000未満 |
| 格子 | 正方格子 |

| 境界 | 範囲外を参照しない。現在ループ無効 |
| 初期配置 | 重複なしでランダム150セル |
| 初期草量 | 各セル1 |

| 成長量 | 1回の更新につき+1 |

生成時のシードは通常ランダム。Grass FieldのrandomizeSeedを無効にすると
seedの指定値で初期配置を再現できる。動物や採食位相の乱数まで固定する機能ではない。

## 誕生・成長・枯死

更新前の各セルの状態から全域を判定し、結果を同時に反映する。

1. 草量が0のセル：周囲8セルのうち草量>0のセルがちょうど1個なら草量1で誕生。
2. 0<草量<3のセル：草量を+1し、3を超える場合は3に丸める。
3. 更新前に草量が3以上のセル：0へ枯死する。

誕生条件の表記：周辺状態 `(>0)`、数的条件 `(=1)`。
近傍数が0個・2～8個なら誕生しない。小数でも正の草量なら1セルとして数える。
草量の合計ではなく、該当セルの個数を数える。

採食がなければ `1 → 2 → 3 → 0` と進む。
草量3へ到達した更新では枯れず、次の更新で枯れる。
同じ更新内での誕生と成長、枯死と再誕生は重複しない。
枯れるセルも、その更新では更新前の状態に基づき周囲の誕生判定に寄与する。
成長を無効にしても、上限に達したセルの枯死は実行される。

採食後は小数から成長する。例えば0.8は次の更新で1.8になる。
上限に到達する前に採食で減れば、枯死のタイミングも変わる。

## 採食API

```csharp
float eaten = grassField.ConsumeGrass(worldPosition, requestedAmount);
// worldPosition: Vector2、requestedAmount: float
```

- 任意の連続ワールドXY座標から所属セルを求める。100刻みの座標は不要。
- 例：(123.4, −56.7)はセル(51,49)。その領域はX=[100,200)、Y=[−100,0)。
- 指定量と残量の小さい方を消費し、実消費量を返す。
- 空セル・範囲外・非正の消費要求・非有限値・初期化前は0を返す。
- 状態は呼び出し時に減少し、表示はLateUpdateでまとめて更新する。
- 引き算の誤差による微小な残量は相対許容誤差1e-6で0にする。
- Unityメインスレッドから使用する。

草の10秒更新と動物の採食周期は独立している。
処理周期の独立であり、別スレッドによる実装ではない。

## 表示・周辺設定

草量を緑色の濃淡で表示し、0は透明。100×100のテクスチャをPointフィルタで描画する。
白い境界枠は対角(−5000,−5000)～(5000,5000)、線幅5。
カメラは左ドラッグでワールドXYを移動し、Zを維持する。
