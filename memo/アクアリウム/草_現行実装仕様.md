## 誕生・成長・枯死

更新前の各セルの状態から全域を判定し、結果を同時に反映する。

1. 草量が負のセル：更新ごとに+1し、0を超えないように丸める。成長の有効・無効や成長量とは独立。
2. 草量が0のセル：周囲8セルのうち草量>0のセルがちょうど1個なら草量1で誕生。それ以外でも更新ごと・セルごとに0.1％の確率で草量1が自然発生する。
3. 0<草量<上限のセル：成長が有効なら指定成長量を加え、上限で丸める。
4. 更新前に草量が上限以上のセル：deathAmountへ枯死する。

自然発生は近傍条件とのORで `UnityEngine.Random.Range(0f, 1f) < 0.001f` を判定する。近傍条件成立時は抽選しない。負の回復中セルは抽選対象外。Unityの共有乱数を使うため、草の初期配置seedだけでは自然発生の推移を固定できない。

誕生条件の表記：周辺状態 `(>0)`、数的条件 `(=1)`。
草量の合計ではなく、正の草量を持つセルの個数を数える。負のセルは数えない。

現在は上限3のため、採食がなければ `1 → 2 → 3 → -1 → 0` と進む。
例えばdeathAmountを-3にすると `1 → 2 → 3 → -3 → -2 → -1 → 0`。
小数も指定でき、-0.5は次の更新で0となる。0を指定すると従来どおり即座に空セルへ戻る。
負から0に回復した更新では誕生せず、次の更新から誕生条件を判定する。
同じ更新内での誕生と成長、枯死と再誕生は重複しない。
枯れるセルも、その更新では更新前の状態に基づき周囲の誕生判定に寄与する。
成長を無効にしても、上限に達したセルの枯死と負の値の回復は実行される。
採食によって草量が0になった場合は負にせず、そのまま空セルとなる。

## 採食API

```csharp
float eaten = grassField.ConsumeGrass(worldPosition, requestedAmount);
// worldPosition: Vector2、requestedAmount: float
```

- 任意の連続ワールドXY座標から所属セルを求める。100刻みの座標は不要。
- 例：(123.4, −56.7)はセル(51,49)。その領域はX=[100,200)、Y=[−100,0)。
- 指定量と残量の小さい方を消費し、実消費量を返す。
- 空セル・負のセル・範囲外・非正の消費要求・非有限値・初期化前は0を返す。
- 状態は呼び出し時に減少し、表示はLateUpdateでまとめて更新する。
- 引き算の誤差による微小な残量は相対許容誤差1e-6で0にする。
- Unityメインスレッドから使用する。

草の15秒更新と動物の採食周期は独立している。長いフレームでは草は経過した周期数だけ更新する。
処理周期の独立であり、別スレッドによる実装ではない。

## 表示・周辺設定

草量を緑色の濃淡で表示し、0以下は透明。80×80のテクスチャをPointフィルタで描画する。
白い境界枠は対角(−4000,−4000)～(4000,4000)、線幅5。
カメラは左ドラッグでワールドXYを移動し、Zを維持する。
