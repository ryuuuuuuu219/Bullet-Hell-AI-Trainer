草のセル・オートマトン仕様まとめ v0.3
『弾幕×アクアリウム』における草の繁殖システムについて、これまでの決定事項を統合します。
六角格子は廃止し、正方格子・8近傍を固定仕様とします。カードによる繁殖規則の変更と、複数の繁殖方式の併用は維持します。
1. フィールド・セル構造
変数	設定値	扱い
FieldSize	1000 × 1000 U	基本設定
CellShape	正方形	固定
CellSize	10 U	カード変更候補
CellCount	100 × 100 = 10,000	自動算出
NeighborhoodType	ムーア近傍（8近傍）	固定
BoundaryMode	未定	未確定
セルはそれぞれ草の量を保持し、その値が成長段階も兼ねます。
2. 草の状態
変数	設定値	扱い
GrassAmount	0〜成長上限	セルごとに保持
MaxGrass	10程度	カード変更可能
InitialSpawnCount	150点	基本設定
InitialSpawnMode	ランダム	基本設定
InitialGrassAmount	1	固定
IncreaseAmount	+1	カード変更可能
草量の意味は以下のとおりです。
- 0：草が存在しない
- 1：草が発生した状態
- 2〜9：成長中
- 10：成長上限（初期案）
草食動物が摂食した場合は、対象セルの草量を減少させる想定です。
3. 誕生・成長規則
変数	現在値	扱い
BirthCondition	(>0)>0	カード変更可能
GrowthCondition	true	カード変更可能
BirthTarget	GrassAmount == 0	固定
IncreaseAmount	1	カード変更可能
UpdateMode	同時更新	固定
誕生条件の解釈
(>0)>0
これは、8近傍のうち草量が0を超えるセルが1個以上存在すれば条件成立、という意味です。
成長条件の解釈
true
草量が1以上のセルは、成長上限に達していなければ無条件で成長します。
状態遷移
初期設定では次の処理になります。
草量 = 0
    ├─ 誕生条件成立 → 草量 = 1
    └─ 誕生条件不成立 → 草量 = 0

草量 > 0
    ├─ 成長条件成立 → 草量 + 1
    └─ 成長条件不成立 → 草量維持

最終草量 = Clamp(計算結果, 0, MaxGrass)


誕生と成長は、同じ更新回で重複適用しない想定です。
4. 更新方式
変数	設定値	扱い
UpdateInterval	10秒	基本設定
UpdateScope	全域	固定方針
UpdateMode	同時更新	固定
AnimalSync	非同期	固定
RuleMergeMode	未定	未確定
10秒ごとに全10,000セルを判定し、すべてのセルが更新前の状態を参照してから、一括で新しい状態を反映します。
動物の移動・摂食などの処理とは独立した周期で実行します。これは処理周期の非同期であり、マルチスレッド化を必須とするものではありません。
5. 搬送体（Carrier）
搬送体は、繁殖規則をどこで実行するかを決める仕組みです。
初期状態では搬送体を使用しませんが、カードで追加・変更できる構想です。
種類	識別子	動作
なし	None	全域のセル更新
固定型	Static	特定地点に留まる
自律移動型	Autonomous	独自の移動規則に従う
動物追従型	Attached	動物に付着して移動する
搬送体の変数候補
変数	内容
CarrierCount	搬送体の個数
Position	現在位置
MovementType	移動アルゴリズム
MovementInterval	移動間隔
MovementDistance	1回の移動距離
MovementCondition	移動条件
EffectRange	規則の作用範囲
CarrierRules	搭載する繁殖・成長規則
AttachedAnimal	付着対象の動物
自律移動型にはラングトンのアリ方式を含めます。
動物追従型では、動物の移動先や通過地点に繁殖規則を適用する方式が考えられます。
6. カードによる変更
カードは草の数値だけでなく、繁殖アルゴリズム自体も変更できる設計です。
カード分類案	変更対象
セル寸法	CellSize
成長上限	MaxGrass
誕生条件	BirthCondition
成長条件	GrowthCondition
増加量	IncreaseAmount
更新周期	UpdateInterval
繁殖方式	ReproductionRules
搬送体	CarrierType, CarrierCount
移動方式	MovementType
規則の作用範囲	EffectRange
複数の繁殖方式は併用可能です。
例えば、通常の近傍繁殖に加えて、ラングトン型の自律移動による散布と、動物追従型の散布を同時に実行できます。
ただし、複数規則が同じセルに作用した場合の合成方式は未確定です。

現時点での基本ルールは、**「10秒ごとに、草のあるセルは+1成長し、その周囲8セルの空き地にも草が誕生する」**というものです。
これを基準に、カードで繁殖条件や搬送体を追加していく構造になります。
なお、この初期ルールには枯死がないため、動物による消費がなければ、草はフィールド全体に広がり、最終的に成長上限へ到達します。草食動物を加えた際の持続性は、別途検証する必要があります。
