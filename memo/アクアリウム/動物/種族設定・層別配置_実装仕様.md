# 種族設定・層別配置

更新日：2026-10-27。今回の種族管理基盤の実装仕様。追加予定種の個別能力の完成を意味しない。

## 設定と実行時状態

- `SpeciesDefinition` は種族ごとのScriptableObject。文字列ID、表示名、traits、初期HP、追跡対象ID配列、射撃・加速のbool、射撃間隔・弾速・威力・減衰、旋回速度・停止/再開距離、肉食の輪郭を保持する。
- 既存種は `Assets/Settings/herbivore.asset` と `carnivore.asset`。IDもそれぞれ `herbivore` / `carnivore`。既存の能力値と初期配置値を移行した。
- `AquariumStartupSettings.layers[]` は層別の配列。各層の `species[]` に種族アセット、初期個体数、seed、ランダムseedの有無を置く。保存アセットは草食・第一層肉食・第二層肉食・第三層肉食の4枠で、第三層は空。2026-10-27の追加実装で第一層に犬型・ヨッシー型、第二層に蛇型・甲虫型を登録した。層名は整理用で、攻撃対象や追跡対象を自動決定しない。
- 草設定は同アセットの `grass`。動物Prefabは全体設定の `herbivorePrefab` / `carnivorePrefab`。全肉食種で後者を共有する。
- 種族設定はプレイ前に編集する。traitsは個体生成時にコピーする。個体一覧はアセットへ保存しない。

## シーン・生成・繁殖

各ステージシーンに、種族ごとに `HerbivoreManager` または `CarnivoreManager` を直置きする。マネージャーの `startupSettings` と `speciesId` を設定する。種族設定は文字列IDから層をまたいで検索する。

同一IDの設定重複、同一IDのマネージャー重複、設定欠落はエラーにして生成しない。既存battle0の2マネージャーは移行済み。

各マネージャーの `SpeciesPopulation` が種族アセットと配下の個体一覧を保持する。生成・再有効化で登録し、死亡・無効化で解除する。出生成功率は従来どおり同種生存個体数から計算する。

共有Prefabの `SpeciesIdentity` は生成元マネージャーの種族アセットを参照し、その文字列IDを公開する。子も同じマネージャーから生成するため、親の種族設定を継承する。Prefabの識別設定を種ごとに書き換える必要はない。

## 追跡・攻撃・炭素

`pursuitSpeciesIds` と相手の `SpeciesIdentity.SpeciesId` を大文字小文字も含めて完全一致で照合する。空配列は追跡しない。既存carnivoreは `herbivore` のみ。発見・追跡断念・最寄り選択の既存条件も適用する。

2026-10-27更新：追跡対象配列は通常弾の命中対象にも適用する。対象外は通過する。反射後の無所属弾はこの制限を受けない。逃走対象配列と戦艦型グループ指定も追加した。炭素吸収対象は変更しない。同種へ命中可能な設定の場合、所属弾の同種ダメージは0.1倍。弾・炭素ドロップにも文字列IDを渡す。同種炭素は吸収不可。炭素粒子は生成からゲーム内180秒で残量ごと消失する。

肉食の共通 `SkillSwitch` は種族アセットの `shoot` / `accel` を参照する。個体の射撃タイマーは共有しない。

## 全滅・観測

1体以上生存した種族が0体になった際に、`BattleSimulationSpeed` が `Time.timeScale` を0.1へ上書きする。初期数0の未配置種では発動しない。同じ全滅状態で繰り返し上書きしない。復活後に再全滅した場合は再発動する。

速度ボタンを押すと上書きを解除して1倍速に戻り、以後は2→4→8→1。別種の全滅は新たに0.1倍速を発動する。シーンの速度UIを無効化・終了すると通常速度へ戻す。

画面には種別個体数を表示する。既存eventlogの集計列を残し、種別のcount/carbon列、種別seed、全滅イベントを追記する。種別列は開始時のマネージャー一覧をID順で固定する。`#` 行は注記として扱う。

## 種の追加手順

1. Projectの `Create > Aquarium > Species` で種族アセットを作り、重複しないIDと特徴を設定する。
2. 全体設定の該当する層のspecies配列に登録し、初期数とseedを設定する。
3. ステージに同じ `CarnivoreManager` を追加し、全体設定とそのIDを指定する。肉食Prefabは共通のまま。
4. 追跡対象の種族IDを配列に指定し、種別ログ・出生した子のID・全滅時速度をPlay Modeで確認する。

追加予定は [肉食動物と攻撃手段](ブレインストーミング_肉食動物と攻撃手段.md) を参照する。犬型・ヨッシー型・蛇型・甲虫型の専用能力とアセットは追加実装済み。撃破時繁殖は命中時繁殖へ変更された。艦型・砲台は未実装。能力のboolと数値、調整値、追加種の配置は [追加肉食4種の実装仕様](追加肉食4種_実装仕様.md) を参照。
