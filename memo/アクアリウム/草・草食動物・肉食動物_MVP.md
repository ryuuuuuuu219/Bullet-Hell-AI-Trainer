# 草・草食動物・肉食動物のMVP

作成日：2026-10-23

## 方針と位置づけ

確定した方向性：草・草食動物・肉食動物で3段階の生態ピラミッドを形成するMVPを目指す。
これまでの多層肉食動物・艦型・砲台・特殊能力の議論は、[ブレインストーミング](ブレインストーミング_肉食動物と攻撃手段.md) として分離する。

以下はMVPの確定仕様を記録した設計メモ。2026-10-24に基本肉食動物と動物の被弾処理を実装。実装・検証状況は末尾を参照。
種類別表の提案値はユーザー指定により確定した。仕様確定は実装済みを意味しない。旧ブレインストーミングの種類別数値を自動採用しない。

最小構成は各段階1種。基本の資源の流れを「草 → 草食動物 → 肉食動物」とする。追加指定により、肉食動物同士の攻撃・資源奪取も可能とする。
これは捕食階層を示すもので、個体数や資源量が常にピラミッド状になることを保証するものではない。

## 種類別の対応表

元メモの種類・階層・弾幕・発射間隔・速度・角速度制限・追跡ロジック・特徴・砲台マウント・弾幕の衝突／攻撃／資源奪取対象・追跡対象・描画・HPに対応する。

草食動物は弾幕を使わず、現在セルから草を消費する既存方式を維持する。
「弾幕の衝突・攻撃対象＝資源奪取対象」は弾幕を持つ肉食動物へ適用し、草食動物の採食を弾幕化しない。
HPと体内資源は別の値とする。草食動物の初期資源10・資源上限50をHPへ読み替えない。
動物の移動は現行と同じワールドXY・Z維持とし、肉食動物はフィールド境界では中央に回頭・直進する。草食動物の既存の境界処理は維持する。

## 描画ルール（上位の食性層への拡張を含む）

- 基本肉食動物（第一層）は三角形とし、食性の層が1段上がるごとに頂点数を1つ増やす。
- 第二層は四角形、第三層は五角形とし、第n層の肉食動物は頂点数n＋2の多角形で描画する。
- 肉食動物は各層とも、進行方向に頂点の1つが位置する向きに描画する。
- 上位層の描画ルールは確定事項として記録する。現在のMVPの実装対象は基本肉食動物1種とする。

## 追加確定事項：弾幕・HP・資源

### 発射と命中

- 弾速250 U/s、半径5 U。
- 発射位置は自身の座標で統一する。
- 照準許容角・偏差射撃はなし。「許容角なし」を0度一致による発射制限へ読み替えない。
- 動物に命中したとき、HPと弾の威力を互いに減らす。動物はHPが0以下で死亡、弾は威力が0以下で消滅する。装甲がある場合の実HPの変化は下記の指定式に従う。
- 装甲ボーナスがない場合、命中直前のHPをH、威力をPとして、HPはmax(0, H−P)、威力はmax(0, P−H)になる。同値なら両方0となる。
- 威力が残る弾は、この命中だけでは消滅しない。
- 装甲は草のみ10、草以外は0（草食動物・肉食動物とも0）。装甲は消費せず、被弾ごとに無条件で適用する。
- 実HPの指定式は `HP -= 威力 - 装甲`。ダメージを0以上に丸める補正は指定されていないため追加しない。
- 威力が装甲未満なら、指定式ではHPが増える。動物のHP上限は初期HPの2倍とする。
- 威力が残っても、同一の弾は同一個体へ再命中しない。
- 射程到達時は即座に消滅する。
- 草はHP＝草量×10、装甲10とみなす。`HP = 草量 * 10` → `HP -= 威力 - 装甲` → `草量 = floor(HP / 10)` の順で処理する（小数部切り捨て）。
- 草量の既存範囲は0～3。上記の攻撃変換式と範囲制限との具体的な適用順序は未指定。
- これは草の攻撃判定用の定義であり、肉食動物の弾幕対象へ草を追加する指定ではない。

### 撃破・資源移行・回復

- 肉食動物が攻撃から資源を得るのは撃破時。草食動物は従来どおり草の採食時に資源を得る。
- 撃破された個体の体内資源を、そのまま採食した側へ移行する。
- この際、移行する資源量と同じ量だけ採食側のHPも回復する。資源・HPはそれぞれ加算後に上限へクランプする。
- 資源上限は50。HP上限は初期HPの2倍（草食動物60、肉食動物100）。
- 草食動物が草を採食した場合も、実際に食べた草量と同量のHPを回復し、上限へクランプする。
- HP0で死亡する。資源0による消滅も草食動物と統一する。
- 肉食動物の攻撃対象には、草食動物に加えて自身以外の肉食動物を含める。肉食動物のHPはこの相互攻撃でも使用する。
- 攻撃対象の追加だけから追跡対象も変更したとは扱わない。追跡対象は表の生存する草食動物とする。

### 肉食動物の資源・繁殖・個体数

草食動物と統一し、初期個体数のみ15に上書きする。
以下の数値は「草食動物_現行実装仕様.md」に記載された現行値に対応する。

| 項目 | 草食動物の現行値 | 肉食動物のMVP指定 |
| --- | --- | --- |
| 初期資源（初期個体・子） | 10 | 10 |
| 資源上限 | 50 | 50 |
| 維持費 | 毎秒0.2、移動・停止共通 | 毎秒0.2、移動・停止共通 |
| 繁殖条件 | 資源40以上 | 資源40以上 |
| 繁殖コスト | 親から30減算 | 親から30減算 |
| 1回の繁殖 | 子1体 | 子1体 |
| 初期個体数 | 50体 | 15体 |
| 資源による消滅条件 | 資源0 | 資源0 |
| 繁殖判定タイミング | 採食を試みた時 | 撃破時（資源移行・回復後） |

肉食動物の繁殖判定は現段階では撃破時とする。将来は資源量変化時へ拡張する方針だが、現在のMVP仕様とは分ける。

### 追跡の判断と保持

- 肉食動物の追跡判断周期は1秒。
- 一度選んだ対象は、対象の死亡以外では変更しない。距離・射程・探索範囲から外れたことだけでは対象を変更しない。
- 対象死亡から次の1秒周期までの間、および境界処理では、中央に回頭・直進する。対象保持とは別の移動制御として扱う。

## 確定仕様から分かる挙動・実装時の注意

- 動物の装甲は0なので、威力10の弾が命中するとHPは10減る。途中の回復がなければ、初期HP30の草食動物は3発、初期HP50の肉食動物は5発で死亡する。
- HP・弾威力の相互減算には、減算後の値をもう一方へ逐次流用せず、命中直前の値を使用する。
- 装甲の「HP側へボーナス加算」を残弾威力へ適用する具体式は、今回指定された実HPの式とは別である。残弾威力からHPのみを引くか、HP＋装甲を引くかは明示されていない。現行MVPの攻撃対象である動物は装甲0のため、どちらでも同じ結果となる。
- 草の攻撃変換時の範囲制限順序は未指定。既存表の値が確定したことから、未提示の値を補わない。

持続可能な個体数バランスはまだ実測していない。

## MVPの範囲と確認案

MVPでは草の増減、草食動物の採食・繁殖・死亡、肉食動物の追跡・射撃・資源獲得・繁殖・死亡を観察できる状態を目指す案。
多層肉食動物、砲台、反転、誘導、比例航法、突然変異、生態系同士の対戦は、このMVPの対象外とする案。

確認案：ゲーム時間5分の試行で、草総量・草食動物数・肉食動物数と出生／死亡／捕食数を記録する。
捕食と肉食動物の資源増加が対応すること、3段階すべてが試行終了時に残ることを最初の調整目標とする。
これは長期安定の証明ではなく、バランス調整用の初回観測とする。

## 実装・検証状況（2026-10-24）

- `syogi/Assets/Scripts/Carnivores/` に基本肉食動物の追跡、射撃、撃破時の資源移行・回復、繁殖、飢餓死、状態表示を実装。
- `syogi/Assets/Scripts/Animals/` に動物共通のHP・資源と被弾処理を実装。動物の装甲は0。草への攻撃処理は対象外。
- `Carnivore.prefab` を作成し、`battle0.unity` に初期15体の管理オブジェクトを追加。草食動物・肉食動物の個体数を分けて表示する。
- 描画は灰色、外接円半径80 Uの三角形。輪郭線は現行の草食動物プレハブと同じ線幅10 Uを採用。頂点の1つが現在の進行方向を向く。`foodLayer` が1なら三角形、2なら四角形、3なら五角形となる描画対応を追加したが、上位層の行動・食性は未実装。
- 弾の命中は動物中心から半径80 Uの円と弾半径5 Uで判定する。肉食動物の三角形にも外接円による判定を採用。弾の移動区間を走査し、近い接触順にHPと威力を処理する。同一弾・同一個体の再命中を防止する。
- 弾は射程200 Uで消滅。射手の死亡後も残弾は進むが、死亡した射手は資源・HPを受け取らず復活しない。
- 子は初期HP50・資源10で生まれ、草食動物と同じく親と逆方向を初期進行方向とする。
- コンソールテストで被弾・撃破・貫通時の相互減算、資源移行、回復・上限、繁殖、飢餓、弾の移動区間の接触判定を確認。既存の草・草食動物テストも通過。
- Unity DLLを参照した外部コンパイルは通過。Unity Editorでのインポート・Play Modeの表示と挙動、5分間の生態系バランスは未確認。
