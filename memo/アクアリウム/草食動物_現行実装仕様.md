# 草食動物の現行実装仕様

更新日：2026-10-26。対象：main / syogi / battle0。現行スクリプトと保存設定を静的確認。Play Modeは今回未検証。
全体仕様は [MVP](草・草食動物・肉食動物_MVP.md)、共通の感覚・昼夜・繁殖計算は [共通実装仕様](繁殖・昼夜・休眠・感覚・逃走_実装仕様.md) を参照。

## 初期化・表示

`AquariumStartupSettings.asset`のherbivoresをHerbivoreManager.Startで読み、Herbivore.prefabを50体生成する。
保存設定はrandomizeSeed=false、seed=1。各個体のtraitsは生成時にコピーし、既存個体に後の編集は反映しない。
フィールド全域の連続ワールドXY座標にランダム配置、Z=0。親は右向き、子は親の逆向き。
子の位置は親と同じ。重複排除・草食同士の衝突や押し合いはない。
灰色32角形の輪郭、プレハブ線幅10 U。半径はmax(5,(ln(現在HP)+0.1)×20)で、初期HP30では約70.02 U。
右上にHP・炭素・SPを小数1桁表示。ズーム時も画面上の文字サイズを維持し、休眠表示を追加する。

## HP・資源・採食

| 項目 | 現行値 |
|---|---|
| 初期HP / 上限 | 30 / 60 |
| 初期配置資源 / 上限 | 10 / 50 |
| 資源・HP・SPの型 | double |
| 初期SP / 上限 | 50 / 100 |
| 移動SP費用 | 毎秒0.2 |
| 炭素維持費 | 活動中は毎秒0.2、休眠中は0 |
| 走行追加SP費用 | 毎秒15 |
| 1回の採食要求 | 最大1 |
| 採食対象 | 中心が属する1セル |
| 採食・回復 | 草の実消費量を炭素へ加算。HP・SPは炭素量×0.2/秒、休眠中3倍で各上限まで回復 |
| 死亡 | 炭素・HP・SPのいずれかが0以下。残存炭素を粒子化 |

採食カウンターは初期0。活動フレームで正ならdeltaTimeを引き、0で止める。
0なら採食を試み、実消費量をカウンターに加える。1食べれば1秒、0.3なら0.3秒。草がなければ0のまま。
長いフレームの失われた採食周期をまとめて実行しない。移動で草セルへ入ったときにも採食を試みる。
休眠中はカウンターを停止。走行中は減算するが採食はしない。体の半径は採食範囲ではない。
AnimalBody.Update（実行順0）が維持費・HP/SP回復・活動年齢・脅威を処理し、HerbivoreFeeding（10）が採食・繁殖、HerbivoreMovement（20）が移動を処理する。
維持費で死んだ個体を同フレームの採食で復活させることはない。

## 繁殖

保存traitsは資源下限40、成熟30活動秒、子1体、子炭素10、出産SP10/回。コスト倍率は将来用でMVPでは使わない。
成熟済み・資源下限以上・全コストを支払える・活動中・非逃走中を条件に毎フレーム最大1回判定する。
採食成功時だけの判定ではない。親から出産数×子炭素とSP10を引き、子を生成する。炭素・SPの費用不足なら両方とも引かない。
親子とも活動年齢は生成時0。成熟は一度限りで出産後にリセットせず、専用クールダウンはない。
子は初期HP30、指定炭素、SP50、初期採食カウンター0で生まれる。親のHP・採食カウンターを継承しない。
繁殖相手・個体数上限・遺伝・突然変異はない。死亡時の残存炭素は粒子として還元する。

## 通常移動・草探索

通常速度80 U/s、最大角速度90°/秒。ワールドXYを移動しZを維持する。
探索距離は500×lerp(0.5,1,明度) U。円形範囲内のセル中心に正の草量があることを候補条件にする。
草探索には動物間の隠蔽・中心間遮蔽を使わず、距離と以下の評価を使う。

```text
内積 = 正規化した進行方向と目標方向の内積
方向重み = (内積 + 1) × 0.4 + 0.2
評価値 = (草量 / 10) × 方向重み
```

正面1、横0.6、後方0.2の重み。同評価（許容差1e-9）なら内積、次に距離の短さを優先し、それも同じなら走査順。
現在セルに草があれば停止。草なし・候補なしなら直進。目標セルへ入れば到達とする。
判断は1秒周期に加え、開始時・採食直後・休眠からの復帰・走行状態の切替時にも行う。
毎フレーム最大0.02秒刻みで旋回・移動し、移動で草セルへ入ると停止・採食を試み、そのフレームの残りの移動を終える。

## 逃走・境界

発見可能な最寄りの肉食から離れる方向を目指す。草による隠蔽・遮蔽も検知距離へ反映する。
肉食が自分を追うかどうかには関係なく脅威として扱う。最後の検知後も2活動秒逃走を維持する。
走行速度150 U/s、草セルでも停止せず、採食・繁殖は停止する。
逃走の累積活動2秒ごとに10％でXY方向を＋90°回す。回避自体のHP・資源コストは0。
通常旋回制限に対する例外で、回避発生小ステップは通常旋回を行わない。非逃走・休眠中は回避時計の残りを保持する。
乱数はマネージャーのActualSeedと個体登録IDから生成する。
境界では内側への旋回を優先し、余裕は2×現在速度÷(90°をrad換算した角速度)＋現在半径。
中心を[-5000,4999.999]へ制限する。外周全体の枠内収容や境界で一定の実移動速度は保証しない。

## 休眠・被弾・観測

草食は光量0.2以下で休眠し、移動・採食・繁殖・成熟を停止する。休眠中の炭素維持費は0で、HP・SP回復は3倍になる。
表示・被発見・被弾は維持。脅威による自動覚醒はない。
弾と対象の種族ID一致時はHPダメージを1/10にする。未指定IDは草食1。HP0で残存炭素を粒子化し、接触した動物が吸収する。
全体UIに個体数、eventlogに個体数・資源総量等の周期記録がある。出生・死因別死亡・捕食件数は未集計。
過去の「増加傾向」という観測は現在設定の長期安定を証明しない。
