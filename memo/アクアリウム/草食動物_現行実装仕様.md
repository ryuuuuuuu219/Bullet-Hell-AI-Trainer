## 採食

- 個体ごとの経過時間カウンターで、ゲーム時間1秒ごとに採食を試みる。
- 初回までの位相は個体ごとにランダム化し、一斉採食を避ける。
- 現在の中心座標が属する1セルから最大1を消費する。
- 草が1未満なら実際の残量だけ食べ、0なら何も得ない。
- 草の実消費量と同量を体内資源に加える。草1＝資源1。
- 失敗した採食量を後の回に持ち越さない。
- 半径80は表示形状の値であり、採食範囲の半径ではない。

以前の「毎秒0.2の草消費」は更新済み。現在の0.2は体内資源の毎秒維持費を指す。

## 体内資源・繁殖・消滅

| 項目 | 現行値 |
|---|---|
| 初期資源 | 10（初期個体・子とも共通） |
| 資源上限 | 50 |
| 資源の型 | double |
| 維持費 | 毎秒0.2、移動・停止とも同じ |
| 繁殖条件 | 資源40以上 |
| 繁殖コスト | 親から30を減算 |
| 1回の繁殖 | 子を1体生成 |
| 子の配置 | 親と同じワールド座標 |
| 子の状態 | 新しいプレハブから生成。親の蓄積資源や採食カウンターは引き継がない |
| 消滅条件 | 資源0。即座に非アクティブ化し、オブジェクトを破棄 |

維持費は毎フレームの経過時間に応じて適用する。
採食時刻までの維持費→0判定→採食・回復→移動判断→繁殖判定の順で処理する。
維持費で0になった個体は、その時刻の採食によって復活しない。
繁殖は採食を試みたタイミングで判定し、管理下の個体がマネージャーを通じて行う。
ゲーム時間を停止すると維持費・採食・移動も停止する。

計算上の関係（実測値ではない）：

- 無採食なら初期資源10÷毎秒0.2＝50秒で消滅。
- 毎秒1を食べ続けられるなら、維持費との差は平均+0.8資源/秒。
- 繁殖時は親−30・子+10なので、動物全体の体内資源は差し引き20減る。
- 草の成長による資源供給があり、生態系全体を閉じた資源保存系にはしていない。

設計方針として、資源系の厳密な循環・総量保存は重視しない。
上記の繁殖による差し引き20の減少を、総量保存のために別の資源へ還元することは必須ではない。

## 移動・探索

| 項目 | 現行値 |
|---|---|
| 移動方向 | 正規化したVector2を保持。初期は右向き |
| 移動中の速度 | 100 U/s |
| 最大角速度 | 90 deg/s |
| 座標 | ワールドXYを移動し、Zは維持 |
| 通常の目標判断 | 個体ごとに1秒周期。開始時と採食直後にも判断 |
| 探索範囲 | 現在セルを中心とする±5セルの正方形。最大11×11セル |
| 探索対象 | 草量>0のセル。範囲外は除外 |

現在セルに正の草量がある場合は停止し、探索を早期終了する。
実数化後は1未満の草も対象。停止中も採食・維持費・判断は続く。
停止中も進行方向を保持し、最後の草を食べた直後の判断で移動を再開する。
移動中に草のあるセルへ入った場合も、そのフレームで停止する。

候補セルの中心を目標とし、以下の評価値を最大化する。

```text
内積 = 正規化した進行方向・正規化した目標方向の内積
方向重み = (内積 + 1) × 0.4 + 0.2
評価値 = (草量 / 10) × 方向重み
```

方向重みは正面1、横0.6、背後0.2。
草量の除数10は現行コードの値で、上限3への変更後もそのまま。
全候補共通の正の倍率なので候補の順位には影響しない。
同評価なら内積が大きい候補、次に距離が短い候補を優先。
それも同じなら走査順で先に見つかった候補を保持する。
セルを直接走査するため重複排除用の辞書や全候補のソートは不要。
草が見つからなければ直進する。

毎フレーム旋回・移動し、長いフレームは最大0.02秒の刻みに分ける。
目標セルへ入ったら到達扱い。点への完全一致は要求しない。
正方形なので、半径500 Uの円形探索とは異なる。

## 境界と現状の制限

- 境界付近では採食目標より内側への旋回を優先する。
- 中心位置をフィールド内へ制限する安全処理があり、境界では実移動速度が100未満になり得る。
- 境界の旋回余裕は現行コードで `2×旋回半径+6`（約133.3 U）。
  半径80へ拡大した見た目全体の枠内収容は保証していない。
- 親子や個体同士の衝突・押し合い・重なり回避は未実装。
- 繁殖相手、成熟期間、専用の繁殖クールダウン、個体数上限は未実装。
- 肉食動物・捕食・突然変異・遺伝・死骸資源の還元は未実装。
- 個体数・草総量・出生死亡数の時系列記録や集計UIは未実装。

## 根拠・検証

- `HerbivoreManager.cs`：初期配置、子の生成。
- `HerbivoreFeeding.cs`：個別採食タイマー、維持費、資源回復、消滅、繁殖の呼び出し。
- `HerbivoreResources.cs`：資源上限、維持費、繁殖コストと判定。
- `HerbivoreMovement.cs`：移動、停止、旋回、境界回避。
- `GrassTargeting.cs`：正方形探索、方向重み、目標選択。
