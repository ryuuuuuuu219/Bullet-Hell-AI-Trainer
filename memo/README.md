# メモ全体案内

このディレクトリでは、現行企画と過去企画を分けて管理する。

- [アクアリウム](アクアリウム/README.md)：現行の「弾幕×アクアリウム」企画・仕様・検証記録。現在の開発方針はここを基準にする。
- [NN](NN/README.md)：ニューラルネットワーク、学習、弾幕表現、課題・ステージ設計の資料。各文書の確認日と位置づけを参照する。
- [将棋](将棋/README.md)：旧「弾幕魔とコンストラクタ／弾幕コンストラクタ」企画の履歴。現行アクアリウム仕様として扱わない。

文書名に「現行」とあっても、別企画・別実装時点の現行仕様である場合がある。企画をまたいで自動的に流用せず、対象ディレクトリと確認日を確認する。
