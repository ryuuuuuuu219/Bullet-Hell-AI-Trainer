手動操作によるニューラルネットワーク教育方法
確認日：2026-09-09


◇このメモの目的

個体ID 0を人間が操作し、その操作を教師データとしてNNへ学習させる手順をまとめる。

ネットワーク構造、85入力の詳細、逆伝播式については
「memo/NN仕様_現状.txt」を参照する。


◇教師操作

・論理個体IDは0
・StageSelectの「教師モード（手動操作）」トグルがONのときだけ有効
・手動入力を正解として個体0自身のNNを逆伝播で更新する
・設定されたAI個体群とは別にManual Playerとして1機追加される
・GAの成績、親候補、エリート候補から除外される
・自動世代更新の全滅判定には含まれる
・トグル状態はStageシーンへ引き継がれる


◇教育前の設定

1. populationSettingでGAへ参加させるAI個体数を設定する。

教師モード中は、設定個体数とは別にManual Playerが1機追加される。
設定個体数1の場合でも、Manual Player 1機とAI個体1機が生成される。

推奨開始値

・設定AI個体数：5
・教師個体：論理レイヤー0のManual Player 1機
・GA評価個体：論理レイヤー1～5の5機
・実際に生成される総個体数：6機

◇教育の開始

1. StageSelectシーンから課題を選ぶ。

2. Startボタン左の「教師モード（手動操作）」をONにする。

3. StartボタンでStageを開始する。

4. トグル状態がStageへ引き継がれ、論理レイヤー0にManual Playerが追加生成される。

   教師モード中は論理レイヤー0が固定表示される。
   論理レイヤー1以降の自機、敵弾、レーザー、自機弾は描画されない。
   当たり判定やAI処理は継続し、表示だけが隠れる。

5. マウスを動かして回避操作を行う。

自機は現在のマウスカーソル位置へ向かって移動する。
ステージ開始時、マウスカーソルは手動操作自機の位置へ移動する。

移動方向は長さ1以内へ正規化されるため、斜め方向だけ移動速度が速くなることはない。
カーソルが自機に近い場合は移動量を弱め、カーソル位置を通り越さないようにする。
低速移動キーはない。


◇教育中に内部で行われる処理

FixedUpdateごとに次の順序で処理する。

1. 現在のセンサー値、脅威時間、履歴から85入力を作る。

2. 教師個体のNNでXY移動を予測する。

3. 実際の移動にはNN予測を使わず、マウスカーソルへ向かう移動入力を使う。

4. 移動適用直前の85入力をコピーする。

5. その時点の手動入力XYを正解データとする。

6. 採取間隔へ到達していればTeacherSampleを追加する。

7. 追加したサンプルで個体0自身のNNを1回逆伝播する。

教師データ

入力：85個のfloat
正解：手動入力X、手動入力Y

手を離した停止入力（0, 0）も正解として学習する。

◇逆伝播用の正解XY入力経路

逆伝播の正解XYは、次の2経路から入力できる。

・手動教師：マウスカーソルへ向かう移動入力XY
・スクリプト教師：ITeacherTargetProvider.TryGetTeacherTargetが返すXY

どちらも同じRecordTeacherSampleへ入り、長さ1以内へ制限された後、
そのFixedUpdateでNNが参照した85入力と組にして逆伝播へ使用される。

ITeacherTargetProviderを実装したMonoBehaviourを自機へ追加すると、
PlayerMovementControllerがAwake時に自動検出して常時有効にする。
Settingシーンの入力スクロールビュー5項目目「補助用回避ベクトル指示器」で有効・無効を切り替える。
既定はON。設定がまだ保存されていない場合もONとして扱う。

実行中にProviderを差し替える必要がある場合だけ、
PlayerMovementController.SetScriptedTeacherTargetProviderを使用する。

スクリプト教師のXYは逆伝播の正解だけに使用する。
自機の実移動には常にNN予測を使用し、スクリプト教師のXYを直接使用しない。
スクリプト教師が付いたNN個体は専用教師個体とは扱わず、GA評価から除外しない。
スクリプト教師サンプルでは50件ごとの共有保存を行わず、
世代評価で選ばれたGA個体を従来の経路で保存する。

既存の手動教師個体では手動入力を優先し、ScriptedTeacherを追加しない。
ITeacherTargetProviderがfalseを返したFixedUpdateでは、
スクリプト教師のサンプルを記録しない。


◇スクリプト教師の初期実装

専用のScripted Teacher個体は生成しない。
通常課題で生成される各NN個体へScriptedTeacherを追加し、
各個体自身の85入力に対する正解XYを逆伝播する。
個体数と論理レイヤー割当は従来どおり。
Settingシーンで「補助用回避ベクトル指示器」がONの場合だけ、
通常課題の各NN個体へScriptedTeacherを追加する。
OFFの場合はProviderが既に付いていてもスクリプト教師の正解XYを採取せず、
NNの通常入力、NN出力による実移動、GA評価には影響を与えない。
設定はPlayerPrefsの専用キーへ保存し、NN重みの世代保存とは分離する。
Final課題にはScriptedTeacherを追加せず、既存AI評価とランキング経路を維持する。

既定値

・予測時間：2秒
・候補方向：16方向と停止
・候補時間：0秒、0.25秒、0.5秒、1秒
・予測刻み：0.05秒
・LOS角速度閾値：2deg/s未満
・安全マージン：自機当たり判定半径
・前回方向の維持率：0.3
・画面端ペナルティ：なし

候補目標座標をWorldToViewportPointで判定し、
viewport XまたはYが0～1の範囲外なら、その候補は無効とする。
画面端へクランプして評価対象へ戻すことはしない。

脅威がない場合は、StageSpawnManagerの自機配置初期値までの
ベクトルを正解XYとして返す。現在の初期値は(0, -150)。
初期配置付近では1FixedUpdateの最大移動量を基準に減速し、
目標座標を通り越しにくくする。


◇教師データの採取頻度

移動入力あり：0.1秒ごと
停止入力（0, 0）：0.5秒ごと
メモリ上の保持上限：2048件

停止中のデータ採取頻度を下げ、停止データだけが大量に蓄積することを防いでいる。

2048件を超えた場合は最古のサンプルから削除する。


◇操作時の考え方

教師入力は「その場面でどちらへ動くべきか」の正解になる。

教育時は次を意識する。

・危険が来る前から、回避したい方向へ入力する
・画面端へ張り付く操作ばかりに偏らせない
・左右だけでなく上下方向の回避例も与える
・安全な場面では、必要に応じて停止入力も与える
・同じ課題だけでなく、異なる弾幕でも操作例を与える

マウスを急激に往復させる操作が多い場合、似た入力状態へ異なる正解が混在し、学習が安定しにくくなる。


◇Inspectorで確認する情報

実行中の教師個体0を選択し、Aidataコンポーネントを見る。

確認項目

・Debug Threat Time Signal
・Debug Current Sample
・Debug Previous Sample
・Debug Teacher Target
・Debug Teacher Target Source
・Debug Prediction
・Debug Teacher Loss
・Debug Teacher Sample Count

Debug Teacher Target

現在の逆伝播用正解XY。

Debug Teacher Target Source

正解XYの入力元。Manual Pointer、Scripted Provider、またはUnspecified。

Debug Prediction

同じ場面でNNが出した移動予測。
教師モード中の実移動には使用されない。

Debug Teacher Loss

直近に採取した教師サンプルに対する、学習前の二乗誤差。
オンライン学習では入力場面が毎回変わるため、実プレイ中のLossが毎回単調減少するとは限らない。

Debug Teacher Sample Count

現在メモリ上に保持している教師サンプル数。
最大2048。


◇学習率の調整

Settingシーンの世代設定「逆伝播の学習率」で変更する。
保存値はステージ生成時に全個体のAidataへ適用する。

既定値：0.01
設定範囲：0.000001～0.1
スライダー内部値をx=3～18とし、学習率は10^(-x/3)で求める。
x=3で0.1、x=18で0.000001となり、表示値には変換後の学習率を使用する。

Lossが激しく振動する、操作と逆方向へ予測が飛ぶ場合

・学習率を小さくする
・例：0.01 → 0.005 → 0.001

学習がほとんど進まない場合

・急に大きくせず、少しずつ増やす
・例：0.001 → 0.003 → 0.005

勾配はGradient Clampで制限される。
既定値は1。


◇教師NNの保存

保存形式：既存AiSaveData
保存先：既存PlayerPrefsキー

自動保存タイミング

・教師サンプル50件ごと
・世代更新時

世代更新時は、個体0の学習済みNNをスナップショットとして保持してから個体を再生成する。
再生成された教師個体0へ、保持したスナップショットを再適用する。

教育開始直後に終了すると50件へ到達していない可能性がある。
確実に自動保存させる場合は、Debug Teacher Sample Countを確認し、50件以上収集するか世代更新まで続ける。


◇教師NNをAI自身に評価させる方法

人間操作中の生存スコアは、教師NNのAI性能評価には使用しない。

評価手順

1. 教師データを十分に収集し、自動保存を確認する。

2. Play Modeを終了する。

3. StageSelectで「教師モード（手動操作）」をOFFにする。

4. 再びStageを開始する。

5. 個体0を含む全個体がNN出力で移動していることを確認する。

6. AI自身の操作による生存時間、与ダメージ、画面端滞在などで評価する。

保存済み教師NNをGAの初期ネットワークとして利用した場合でも、
教師操作中のスコアは引き継がず、AI自身に操作させた新しい成績だけを使用する。


◇世代更新との関係

教師モードONの場合

・Manual Playerはランキングから除外
・Manual Playerは交叉用の親候補から除外
・Manual Playerはエリート候補から除外
・Manual Playerは全滅判定に含む
・Manual Playerと全AI個体が被弾すると、自動世代更新条件を満たす
・Manual Playerが生存している間は自動世代更新しない

教師個体は世代更新で再生成されるが、NNスナップショットは引き継ぐ。


◇終了時の注意

教育終了後もStageSelectの教師モードトグルがONのままだと、個体0は引き続き人間操作になる。

通常のGA評価へ戻す場合は、StageSelectで教師モードをOFFにする。
教師モードをOFFにしてStageを開始すると、論理レイヤー0の固定表示も解除される。
