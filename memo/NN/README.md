# NNメモ案内

ニューラルネットワークを用いた弾幕回避・学習プロジェクトの仕様、検討、課題設計を分類して保存する。

## 分類

- `現行仕様/`
  - `NN仕様_現状.txt`：2026-08-31確認時点のNN構造・入力・保存方法。こちらを同フォルダ内の旧入力整理より優先する。
  - `AI入力_現状整理.txt`：2026-08-29時点の旧整理。履歴として保持する。
- `学習/`：教師操作、ミニバッチ学習、遺伝保存の改善仕様。
- `弾幕設計/`：矩形補正、現行構造で表現できない弾幕、参考コード断片。
- `ステージ設計/`
  - `Basic設計メモ/`：Basic～Final Challengeの設計記録。
  - `ステージ説明/`：Challenge A～D・Rankingの説明。
  - `ルール統一設計メモ/`：統一ルール、課題テンプレート、区分、要素一覧。
- `企画・履歴/`：初期企画の記録。現在のコード仕様とは区別する。
- `予定/`：当時の予定記録。現行タスク一覧とはみなさない。

Unityでの実動作確認が書かれていない項目は、静的仕様または設計記録として扱う。
