# 旧「弾幕魔とコンストラクタ」メモ

このフォルダは、旧「弾幕魔とコンストラクタ／弾幕コンストラクタ」企画の履歴を保存する。
現在の開発方針は`../アクアリウム/`であり、ここにある顧客嗜好、芸術評価、迎撃、三段階評価などを現行仕様として扱わない。

## 分類

- [企画/企画書.md](企画/企画書.md)：旧企画書。
- [カード・弾幕/カードによる弾幕定義.txt](カード・弾幕/カードによる弾幕定義.txt)：カード合成と弾幕定義の詳細記録。
- [カード・弾幕/弾幕・カード項目まとめ.txt](カード・弾幕/弾幕・カード項目まとめ.txt)：当時の実装と設計項目の整理。

カード、弾幕、シーン遷移など現在もコードが残る要素についても、現行アクアリウムで採用済みとは限らない。再利用時は現在のコードとアクアリウム企画書を再確認する。
