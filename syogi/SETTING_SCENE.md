# setting シーン

メインメニューの既存の「Setting」ボタンで開き、「メニューへ戻る」で戻ります。
`Assets/Scenes/setting.unity` を直接開いて Play でも確認できます。既存の BattleViewControls と同様、UI は Start 時に生成します。編集モードでは Setting ルートのみ表示されます。

ステージ0～8の31ミッションを設計書の記載順で表示します。各ミッションは左に条件・報酬、右に操作をまとめた一行です。ホイール、一覧のドラッグ、右側のスクロールバーで縦スクロールできます。

一覧上部の「機能別」で、草の初期数・草量上限／草の繁殖条件／草のサイクル時間／個体数比例繁殖・基準数／昼夜の速さ／戦艦型の初期目安区画数／タイムスケール／次ステージ開放の順にまとめます。同じ機能内はミッション順です。「ミッション順」で元の順序へ戻ります。現在の並び順のボタンは操作不可になり、切替時は一覧の先頭に戻ります。設定値・トグル状態は切替前の値を保持します。

## 操作と実装境界

- 基準数指定には種ごとのトグルと整数スライダーを置いています。同じ報酬に複数種がある場合も同じ行内に並びます。
- 草サイクルは15～60秒、昼夜は30／60／90秒の3段階です。
- 0-2は草の初期数20～150（初期値20）、草量上限2～10（初期値2）です。
- 0-4は隣接生存セル数の最小・最大をそれぞれ1～3の整数で指定します（初期値はいずれも1）。最小が最大を超える操作では最大を、最大が最小を下回る操作では最小を追従させます。
- 上記4項目の解放前の初期値はユーザー指定により各範囲の下限です。設定UIの初期値に反映済みですが、解放判定とバトルへの適用は引き続き未接続です。
- 8-2の範囲は、設計書が優先を明示する後半の個別報酬欄（巡洋艦型0～5、戦艦型0～3）を採用しています。前半の表の0～10とは不一致があります。
- タイムスケールの開放順は1（初期）／1.5／2／3／4／6／8／10／15／20／0.1／0（停止）です。11件の報酬を獲得するごとに次の倍率を開放します。特定のミッションに特定倍率を固定するものではありません。
- タイムスケール報酬は上記の開放順を表示します。報酬連携は未接続のため、次ステージ解放と同様、操作不可のトグル表示です。チェック状態は達成状況を表しません。戦艦型目安区画数も引き続き操作不可です。
- 設定操作はUIのセッション状態です。メニュー往復で保持し、Play終了・アプリ再起動でリセットします。ミッション達成判定・機能解放・バトルへの適用・永続保存は未接続です。上部にもこの境界を明記しています。
- 初期値未指定の操作はUI確認用に範囲下限、トグルOFFから開始します。ゲームの初期値として決定したものではありません。基準数0に特別な意味は付けていません。
- バトルから設定への入口は追加していません。旧CardSetシーンとカード処理は保持しています。

## 変更ファイル

- `Assets/Scenes/setting.unity` と `.meta`：設定シーン、日本語フォント参照。
- `Assets/Scripts/View/SettingScene.cs` と `.meta`：既存uGUI・Input Systemに合わせた一覧UIと操作値保持。
- `Assets/Scripts/View/SettingMissionCatalog.cs` と `.meta`：ミッションの条件・報酬・順序。
- `Assets/Scenes/main menu.unity`：既存Settingボタンの遷移先を変更。
- `ProjectSettings/EditorBuildSettings.asset`：settingを追加。
- `SETTING_SCENE.md`：使い方・仕様上の未接続範囲。

## Unityでの確認項目

メニューから開き、0-1から8-4までスクロールし、1-2の値とトグルを変更してメニュー往復後の保持を確認してください。2-4が30／60／90秒のみを選べること、4-2の4種を個別操作できること、戻るボタンが固定表示されることも確認対象です。
