# 2D宇宙戦争 企画書

初稿｜2026年11月7日  
仮称｜2D宇宙戦争  
ジャンル｜2D TPS・宇宙戦艦砲撃戦

## 1. コンセプト

惑星の重力と遮蔽を利用して射線を作り、遠距離を飛んだ一射で敵艦の装甲を貫き、砲塔や弱点区画を破壊する。舞台は太陽系とは別の恒星系。惑星や要塞の位置が時間とともに変わるマップで、敵勢力の拠点を攻略する。

- **恒星系規模の戦い**。恒星、惑星、小惑星の位置と重力を利用する。艦や砲弾の軌道にスイングバイを使い、惑星を盾に敵の射線を切る。
- **艦体規模の戦い**。区画分けされた敵艦に対し、装甲の薄い角度や砲塔、弱点を狙う。精密射撃を繰り返して敵の戦力を削り、撃破する。

## 2. シリーズと流用資産

作中では、前作にあたる『【天塚先輩と僕シリーズ】 弾幕生態系シミュレーター』が公開済み。そこで生まれた内部文明が、今度は主人公と天塚巫与に「宇宙戦艦ごっこ」を持ちかける。前作の制作はノベルパートの物語を完結させるところで区切り、次作へ移行する。

前作の**戦艦型動物の形状・区画生成**を艦体建造に流用する。生成された形状と区画は、装甲の貫通、区画損傷、砲塔破壊の判定に用いる方針。

## 3. ゲーム進行

1. **行き先を選ぶ。** 軌道を演算する恒星系マップ上の惑星、ラグランジュ点、移動天体などをステージに指定する。ステージ素案の攻略先は最初から選択できる。
2. **高速巡航する。** 目的地までの最短経路を最大船速で進む。艦の移動は光速未満を想定し、1000倍などの時間加速で移動を進める。
3. **巡航中の攻撃に対処する。** 長距離攻撃を自動検知したら時間倍率を等速に戻し、迎撃・戦闘モードに入る。自動検知の対象外となる攻撃もある。
4. **到着して戦う。** 戦闘モードで旗艦または指定された撃破目標を倒すとクリア。帰還行程は省略する。
5. **戦果を反映する。** 入手した兵装・設備と習得した戦術を以降の出撃に使う。

序盤は惑星やラグランジュ点の拠点奪取を想定する。内側に敵拠点を残して外縁部へ進むと、巡航中に飽和攻撃を受ける危険がある。敵勢力は序盤は本腰を入れず、進行後半になるにつれて主力艦隊を差し向ける。後半への移行条件は未定。

## 5. 砲撃、着弾観測、艦載機

### 軌道砲撃

代表的な交戦案は、惑星の低軌道にいる自艦から、高軌道を回る敵艦への砲撃。飛翔中に敵艦が移動するため、着弾時の位置を見越して撃つ。惑星の縁を抜ける軌道を選び、敵艦に届く角度から砲塔や弱点を狙う。

惑星を画面中央、自艦を画面下に固定する回転表示を照準モードの候補とする。この表示ではコリオリ効果による見かけの横ずれが現れる。惑星重力で生じる弾道の曲がりと、回転表示で見えるずれは分けて扱う。弾道予測と予想着弾位置の表示は検討案。

### 判定の分離

| 判定 | 処理 |
|---|---|
| センサーの検知 | 巡航中に回避・迎撃を始める機会を作る。 |
| 艦体より広い観測範囲への進入 | 着弾観測モードに切り替え、艦の近くを通る弾を拡大して追う。 |
| 艦体・区画との交差 | 装甲への着弾、貫通、通過区画や砲塔の損傷を判定する。観測モードに入った弾も、艦体をかすめて通過しうる。 |
| 艦載機レイヤーとの交差 | 2D上で重なった際に、確率で回避する。回避時は砲弾がそのまま飛び続ける。 |

艦載機は高度差によるすれ違いや回避機動を確率で表現する。実装案では、同じ弾と機体の一度の交差につき一回抽選する。未検知弾を着弾観測で初めて見せるか、そこで操作を許すかは未定。

## 7. Unityでの実装案

恒星系の位置と速度を2次元の倍精度座標で保持する。描画時はカメラや戦闘地点との差分を取ってからUnityの座標へ変換する。砲弾は恒星系マップから着弾観測まで同じ状態を持ち、命中候補が生じたら、軌跡を敵艦のローカル座標へ変換して区画を判定する。

時間加速中は移動した区間全体を対象に、砲弾と動く艦の観測範囲との交差を調べる。検知や観測範囲への進入が起きた時刻で時間を落とし、以降の計算刻みを細かくする。回転照準表示は物理計算の座標から表示座標へ変換する。

最小試作は、惑星一つ、低軌道の自艦、高軌道の敵艦一隻。惑星に遮られる弾、艦体をかすめる弾、砲塔に命中する弾を同じ流れで比較する。その後に艦載機一機を置き、回避された弾が奥の艦体まで届くことを確認する。

## 8. 残る設計判断

- 旗艦撃破後、その拠点からの長距離攻撃を止めるか。止める案では初回攻略の成果が航路の安全性に反映される。
- 最短航路の定義、移動目標への到着判定、帰還省略後の次回出撃地点。
- 主力艦隊の出現条件と、複数拠点からの飽和攻撃が発生する条件。
- 兵装・戦術の抽選単位、設備ドロップ率、重複兵装と射撃数・弾薬数の換算。
- 未検知弾の扱い、艦載機の回避率、着弾観測中の時間倍率と操作範囲。
