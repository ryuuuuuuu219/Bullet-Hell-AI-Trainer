# Project AYBS — 施設・設備設計

作成：2026-11-20

既存の施設仕様とMVP予定値を集約する。表の空欄は未決定・未指定を表し、0や効果なしを意味しない。設計上の正式採用と、コードへの実装完了は区別する。

## 1. 共通仕様

- 本書では施設・設備を同じ設備設計の対象として扱う。
- 設備は艦形状生成とは独立してコアに配置し、独立した区画を持たない。
- 全種類を標準搭載し、性能値のみをカスタマイズする。同種設備の複数同時搭載・重複合成は行わない。
- 保存形式は実数そのものを小数第4位まで表す文字列（`0.0000`形式）とID。性能計算は建造終了時に行う。詳細は第5節。
- 機動性能は建造時に確定し、区画破壊では再計算しない。電磁障害発動中の実効性能は「仕様：状態異常.md」に従う。
- 耐火素材の装甲、ビームコーティング、火薬搭載量、絶縁層は11月20日に正式設備として採用。これらにも上記の配置・標準搭載・保存方針を適用する。
- 「耐火素材の装甲」は設備名として正式採用する。Basic／ERA／AEMの装甲区画とは区別し、独立した設備区画は生成しない。

### 2.1 発砲遅延装置と散布界

- 性能値pは軽減率。補正後の散布角＝基準散布角×(1−p)。MVPはp=0。
- 散布角は全角で表す。角度αなら照準方向に対して左右各α/2の範囲。基準散布角への下記補正の組み込み方は未決定。

- 散布界は度（°）で表す。
- 散布界補正に用いる同時発射数＝同じ兵装の砲塔区画数。艦全体の砲塔数や、その瞬間に実際に発射する砲塔数では集計しない。
- 散布界補正＝同じ兵装の砲塔区画数×0.4°（全角）。例：小口径砲4基・大口径主砲2基なら、小口径砲の補正は1.6°、大口径主砲は0.8°。
- 弾速のばらつきが増える代わりに発砲遅延装置に似た効果を持つ「戦術」は検討案として扱う。

艦載機はMVP後の建造シーンの艦載機タブで扱う。共通仕様は「仕様：艦載機.md」、機種・データ定義は「定義：艦載機.md」を参照する。CIWSはMVP後の武装として扱い、兵装仕様は「兵器：目次.md」を参照する。

### 2.2 装填装置

- 性能値pは装填時間の短縮率。補正後の装填時間＝基本装填時間×(1−p)。MVPはp=0。

### 3.3 共通の値域・精度

| 項目 | 確定仕様 |
|---|---|
| 減衰率 | 0～0.99（0.00～99.00%） |
| 減衰後の付与量 | 元の付与量 × (1 − 減衰率) |
| 蓄積値上限補正 | −49～0P |
| 補正後の蓄積値上限 | 150P＋上限補正（101～150P） |
| 保持精度 | 小数第4位（0.0001刻み）まで |
| 表示精度 | ％表示で小数第2位まで。例：減衰率0.1234 → 12.34% |

熱量・EMとも共通の値域を用いる。施設による蓄積加算量の軽減は、状態異常の発動前・発動中とも適用する。被弾ごとの加算量を減らす効果であり、既存の蓄積値を減らす効果ではない。区画を経由するごとの減衰なし、蓄積後の毎秒5P減衰とは別の処理。状態異常の発動・継続・回復は「仕様：状態異常.md」を参照する。

## 5. 保存・獲得

保存文字列は実数そのものの`0.0000`形式（小数第4位まで）とする。％表示用に100倍した値は保存しない。例：軽減率12.34%は`0.1234`、倍率1は`1.0000`、速力250は`250.0000`、上限補正−49は`-49.0000`。

保存精度は小数第4位までの切り捨てとする。例：0.12349 → `0.1234`。負値の切り捨て方向は未決定。

データ項目：

```csharp
string EquipmentPerformanceValues;
List<string> PerformanceValues;
List<int> EquipmentID;
```

性能値を文字列で保持し、IDを使って必要な値を取り出す。`0.0000`は小数桁数の指定であり、符号・整数部を含めた文字数は値によって変わる。したがって旧来の6文字固定・`1+6n`による切り出し式は使用しない。

| 接続項目 | 定義 |
|---|---|
| 設備IDの割当 | |
| 各設備の性能値の項目数・正式項目名 | |
| IDと性能値の対応 | EquipmentID[i]とPerformanceValues[i]を対応させる。両配列の長さ・並びを一致させる |
| EquipmentPerformanceValuesへの全体の格納形式 | |
| 複数値の区切り・読み出し方法 | 各性能文字列は`項目名=値`をカンマで区切る。設備IDと項目名で読み出し、項目の順番には依存しない |
| 形式の版番号・更新規則 | |
| 小数第4位に収める際の丸め規則 | 切り捨て（負値の方向は未決定） |
| ステージデータとの接続 | |
| 同一属性へ作用する異種設備の合成式 | |
| 上限補正の％表示への換算 | |

形式例（ID・項目名は説明用）：`EquipmentID=[101,102]`、`PerformanceValues=["speedMultiplier=1.0000,turnMultiplier=1.0000","capCorrection=-20.0000"]`。正式ID・項目名・全体の保存文字列への格納形式・版番号は上表の空欄を埋めて定義する。同一施設の効果は合成しない。

- 敵撃破時のドロップ判定は0.2%。戦艦はコア撃破時のみ。
- ドロップ成立後、兵装／設備を各1/2で選ぶ。設備の無条件確率は0.1%。
- 対象テーブルは撃破対象の搭載設備。性能値はランダムで、基本的に正規分布から抽選する。
- 個別の確定抽選値は第4節。その他の設備の平均・標準偏差は空欄のまま扱う。

### 5.1 所持・装備選択

- 設備の所持上限は設けず、建造中は自由に装備を変更できる。同種設備の複数同時搭載・合成なしは維持する。
- 装備中の設備個体IDをプレイヤーの建造艦データに追加し、選択した所持個体を参照する。設備種別IDとは区別する。個体IDの型・採番は未決定。
- 装備変更中は編集中データを更新し、区画数が一致して恒星系マップへ戻る際にのみ設計・装備選択を保存する。
- 撃破ごとの抽選結果は仮のドロップ品配列に保持する。勝利・プレイヤー撤退成立時に即時所持品へ反映し、沈没時はその仮ドロップ品を破棄する。既存の所持品を破棄する指定ではない。
- 報酬の詳細は「仕様：1115確定事項まとめ.md」のドロップ節を参照する。
