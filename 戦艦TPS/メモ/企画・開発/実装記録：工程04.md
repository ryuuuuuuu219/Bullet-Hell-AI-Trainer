# 工程04：操艦AI 7種類の実装記録

更新：2026-11-21

## 範囲と状態

ロードマップ工程04の操艦処理・共通移動への接続・検証入口を実装した。工程06の共通射撃AI、工程14のステージID解決／敵編成への配線は別工程。既存の試作射撃処理を正式な共通射撃AIとして扱わない。

原典：[戦闘AI仕様メモ](../戦闘/AI/仕様メモ：戦闘AI仕様メモ.txt)。未決定事項は以下の暫定実装と区別し、原典の確定仕様へ格上げしない。総合受入まではロードマップのチェックを据え置く。

## 実装

Unityプロジェクト：`新しいフォルダー/sennkannTPS`。

- `Assets/Script/module/ShipSteeringAI.cs`：C1（純粋追尾）、C2（LOS角速度）、TOr（攻撃対象周回）、Obs（固定中心周回）、DF（護衛対象周回）、AC（停止）、BS（微速・舷側指向）。
- `ShipSteeringSettings`：`major`／`fallback`、攻撃・護衛・代替目標のTransform参照、固定中心のワールド座標、半径。設定はConfigure時に複製。enum番号や参照形式は実装内のものであり、正式な保存ID／ステージファイル形式ではない。
- `ShipBuilder.BuildWithAI(...)`：通常の建造艦を生成しAIを接続する入口。ステージ生成側から設定を渡せる。プレイヤー操作の艦とは区別する。
- AIは実行順25、既存の状態更新20と移動30の間で指示を出す。位置・旋回の適用は既存の`ShipMovement`のみ。EMPの実効旋回上限を共有し、到達制限と速度指示遅延を維持する。
- TOrの既定半径3,000 U、Obsの既定半径2,000 U。DFは正の半径を明示指定する。周回角は75/90/105度を3秒保持、中心方位は毎フレーム更新。不感帯は±10度。中心との一致時は全速直進し、選択済みの周回方向を保つ。
- BSは前進25%、誤差15度超で旋回開始、8度以下で終了。左右は毎フレーム判定する。
- 対象の破棄・非アクティブ化・BattleshipInstanceの死亡を喪失として扱う。周回型の既定代替はAC。指定されたC1/C2と代替目標にも切り替えられる。自動で最寄りの敵を選ばない。

## 未決定に対する暫定実装

| 項目 | 今回の実装 |
|---|---|
| C1の操舵粒度 | 最大旋回速度＋到達制限。任意の追尾ゲインは追加しない |
| C2のLOS計算 | 前フレームとの最短角度差÷deltaTime。初回・中心一致後は初期化し、架空の角速度を発生させない |
| C2の旋回符号 | 原典どおり正は左、負は右。±5度/s閾値と後方90度以上での純粋追尾を維持。衝突到達を保証しない |
| 中心一致判定 | ε=0.001 Uを暫定採用 |
| 周回方向の同角度 | 原典の暫定案に従い反時計回り |
| 設定／対象の切替 | Configureで方向・角度保持・LOS履歴・戦艦型の旋回状態を初期化。喪失後の移行は保持し、主AIへの復帰は明示的な再設定で行う |
| 代替目標不在 | Stop指示＋旋回0とし、MissingTargetを公開。代替目標を勝手に探索しない。Stop指示にも既存のEMP遅延が適用される |
| ACの旋回 | 暫定的に旋回0。停止は推進速度0であり、外部引力は通常どおり作用する |
| 固定中心の表現 | 現時点はワールド座標を明示指定。ステージ相対座標からの解決は後工程 |

## 検証と操作方法

Unityメニュー **戦艦TPS → 試験 → 操艦AI 7種類（工程04）** で、保存済みシーンを変更しない独立した試験シーンを開く。編集中のシーンに変更があればUnity標準の保存確認が出る。

画面上部で7種類を切り替え、目標移動、目標喪失、代替C1への切替、再配置を試せる。水色が自艦と軌跡、赤が攻撃／護衛対象、黄色が代替目標。灰色の円は原点から半径3,000 U。試験画面は比較のため全周回型を3,000 Uに指定しており、Obsの既定値2,000 Uは変更していない。終了はUnityのPlay停止。

自動検証は **戦艦TPS → 検証 → 操艦AI 7種類（工程04）**。建造艦・EMPを含む検証はPlay Modeで実行する。既存の工程02・03 Play Mode検証にも追加した。

隔離したUnity 6000.4.6f1プロジェクトで以下を確認：

- `SHIP_STEERING_CHECKS_PASS`：7種の速度指示、左右旋回と上限、C1到達制限、C2初回・符号・不感帯・90度境界・角度折返し、周回距離帯境界、3秒保持、中心一致、移動中心への追従、Obs固定中心、BSの15/8度ヒステリシス、喪失時切替、代替対象不在。
- `SHIP_STEERING_BUILT_SHIP_PASS`：実際の建造艦へのAI接続、EMP100P以上での旋回停止・速度指示遅延、50Pでの旋回到達制限。
- 周回3種を共通motorで各240秒、刻み0.02秒、速力250 U/s・旋回25 deg/s・固定中心・半径3,000 Uで計算。開始60秒後からの距離範囲は各3,161.08～3,371.09 U、総周回角1,050.25度。半径へ強制投影していない。不感帯と3秒保持により±8%帯の外にも振れるため、任意性能・高速移動中心での安定保証とはしない。
- 既存の`CONSTRUCTION_MOUSE_FIRE_PASS`、`CONSTRUCTION_MOVEMENT_CHECKS_PASS`、`SCRIPT_REGRESSION_CHECKS_PASS`、`CONSTRUCTION_MOVEMENT_PLAYMODE_PASS`も成功。
- `SHIP_STEERING_SANDBOX_PASS`：独立試験シーンの通常Update経路で全速移動を確認。1280×779の実描画を取得し、AI切替ボタン・状態表示・自艦・目標・基準円が表示されることを画像でも確認した。ログは`ValidationWork/ShipSteeringSandbox.log`、画像は`ValidationWork/ConstructionQAImages/steering-ai.png`。

ログ：`ValidationWork/ShipSteeringPlay.log`（検証用・Git対象外）。Unity検索DBの既存の起動時例外が残るが、上記の検証は成功して終了した。

残る確認は実際の敵編成・各艦性能での軌道調整と目視受入。高速の移動中心、艦同士の干渉、C2の到達性の全条件は今回の試験で保証していない。
