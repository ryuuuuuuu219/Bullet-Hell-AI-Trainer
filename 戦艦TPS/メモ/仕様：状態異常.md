# Project AYBS — 状態異常（火災・EMP）

作成：2026-11-18（既存メモから分割）

## 1. 本書の位置づけ

火災・EMPの仕様を決定するため、企画書・弾種別効果・兵器目次・未決定事項から該当内容を集約した。以後、状態異常の詳細は本書で管理する。

今回は資料の分割のみ。以下の既存方針・数値を変更せず、未決定事項も未決定のまま移した。実装済み・動作確認済みを意味しない。

## 2. 共通仕様【既存方針】

| 項目 | 現在の記載 |
|---|---|
| 状態を保持する場所 | 火災・EMPともコア |
| 攻撃側の値 | 弾が熱量とEM付与量を持つ |
| 蓄積する機会 | 区画（コアを含む）を貫通、または爆風が接触するごと |
| 蓄積値の表現 | 火災・EMPそれぞれのパーセンテージ値と同義 |
| 発動閾値 | 蓄積が100を上回ると発動 |
| 回復 | 火災・EMPとも毎秒5パーセントポイント回復 |

区画への蓄積とコアでの状態保持の具体的な対応、蓄積上限、発動後の値は未決定。EMPの発動閾値とレールガン停止条件は異なる記載があるため、第6節で整理対象とする。

## 3. 火災【既存方針】

### 3.1 継続ダメージ

- 火災はパーセンテージで管理する。
- 2秒間隔で10回、ダメージを判定する。
- 判定ごとに「火災の蓄積値×2％」の割合ダメージを与える。
- 割合ダメージはコアHPを基準とする。
- 現在コアHP／最大コアHPのどちらを基準にするかは未指定。

「火災の蓄積値×2％」は元メモの表記を保持する。百分率の数値表現や具体的な計算式を、この分割作業で補完しない。

### 3.2 即席弾引火

- 装薬砲の区画ごとに2％で抽選する。
- 当該区画を中心に、コアHPの25％を基準とするAoEを発生させる。
- 半径はその値に比例する。
- 比例係数、HPの基準、範囲内へのダメージ配分などは未指定。

### 3.3 弾薬庫引火

- 「装薬砲数×0.5％」で抽選する。
- コアを中心に、コアHPの75％を基準とするAoEを発生させる。
- 半径、HPの基準、範囲内へのダメージ配分などは未指定。

### 3.4 兵装・区画破壊との関係

- 装薬砲は火災による引火リスクを持つ。
- 区画の連鎖破壊と、火災の隣接区画への伝播は別に扱う。連鎖破壊の採用だけで延焼を確定しない。

## 4. EMP【既存方針】

- EM付与量の百分率蓄積値として保持する。
- 毎秒5パーセントポイント回復する。
- 設備によるダメージコントロール性能と照準精度が、通常値から一定割合低下する。
- EMPが0％より大きい間、レールガンは射撃できない。
- 装薬砲はEMP下でも射撃可能。
- 性能低下率、蓄積上限、発動後の値は未決定。

## 5. 他の仕様との接続

- **弾種**：熱量・EM付与量や電子ビームのEMP効果は「仕様：弾種別効果_仕様案.md」を参照する。蓄積・発動・継続・回復は本書で扱う。
- **命中補正**：レーダー・空間レーダーの命中補正自体は「仕様メモ：命中率.txt」を参照する。EMPとの関係は未決定であり、本書第6節にまとめる。
- **機動性能**：建造時に最大速力・最大旋回速度を固定し、区画破壊で再計算しない方針は「シーン設計1：艦設計システム.txt」を参照する。EMPによる設備低下との関係は未決定。
- **通常損傷**：HP減少による性能低下を設けない方針と、EMPによる性能低下を区別する。砲塔破壊による射撃不能も別の処理。
