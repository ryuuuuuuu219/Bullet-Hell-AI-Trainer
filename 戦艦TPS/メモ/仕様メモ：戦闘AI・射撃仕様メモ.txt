『2D宇宙戦争』戦闘AI・共通射撃AI 仕様メモ
更新日：2026-11-14

【文書の位置づけ】
これまでの設計会話をまとめた仕様メモ。実装済みであることを意味しない。
「確定」は採用済みの方針、「要詳細化」は追加で条件を決める項目。
兵装個別の発射・誘導・迎撃処理は後日定義する。

============================================================
1. 艦船の共通運動モデル【確定】
============================================================
・基本的に艦首方向へ移動し、横方向への平行移動はしない。
・加速度、旋回加速度、慣性モーメントを扱わない。速度指示は即時切替。
・速度の4段階：
    後進微速 = -0.25 × 最大速力
    停止     =  0
    前進微速 = +0.25 × 最大速力
    前進全速 = +1.00 × 最大速力
・最大速力と最大旋回速度は艦船建造時に計算し、区画破壊による再計算はしない。
・旋回には艦船の最大旋回速度を使用する。

============================================================
2. 操艦AIのラインナップ【確定】
============================================================
(1) 突撃軌道1型
    純粋追尾。目標の現在位置へ艦首を向け続け、前進全速。

(2) 突撃軌道2型
    LOS角速度の3値制御。前進全速。
    艦首と目標方向の角度差が90°以上のときは、1型の純粋追尾で回頭。
    90°未満ではLOS角速度を用いて左右旋回または直進する。
    目標は最終的に衝突コースへ入ること（厳密な比例航法の実装とは限らない）。

(3) 丁字砲撃軌道型
    攻撃対象の現在位置を中心に周回。基準半径3,000 U。前進全速。

(4) 観測・支援射撃型
    攻撃対象から5,000 U離れた固定中心の周囲を周回。基準半径2,000 U。前進全速。

(5) 護衛型
    旗艦など他の味方艦の現在位置を中心に周回。周回半径はステージデータで指定。前進全速。

(6) 砲台・空母型
    移動しない（停止）。艦首自体の旋回可否は別途必要に応じて定義。

(7) 戦艦型
    目標を横側に捉える方向へ旋回し、前進微速（最大速力の25%）で移動。
    距離維持制御は行わない。

============================================================
3. 周回型AI（3・4・5型）の共通制御【確定】
============================================================
・常時前進全速。旋回や軌道修正のために減速しない。
・周回中心を現在位置で参照し、未来位置の予測や目標速度の合成を行わない。
・開始時に現在艦首からの必要旋回量が小さい周回方向（時計／反時計）を選び、原則固定。
・艦首方向と自艦から周回中心への方向がなす角度を距離に応じて設定：
    d < 0.92 R             → 105°（外向き補正）
    0.92 R <= d <= 1.08 R  →  90°（周回方向）
    d > 1.08 R             →  75°（内向き補正）
  d = 自艦と周回中心の距離、R = ステージ指定の周回半径。
・各目標角度の許容誤差は±10°：
    105°のとき95～115°、90°のとき80～100°、75°のとき65～85°。
・許容誤差内なら旋回しない。外れたら最大旋回速度以内で目標方向へ旋回し、1フレーム中に目標方向を通り越さない。
・75°／90°／105°の「目標角度」の選択を3秒ごとに更新し、その間は保持する。
・周回中心への方位、艦首との差、実際の旋回処理は毎フレーム更新する。
・新たに周回開始／中心変更した直後は目標角度を即時初期化。
・自艦と周回中心が重なり中心方向が定義できないときは、艦首を保って前進全速で直進し、距離が有効になれば通常制御へ戻る。
・過去案の「円への接点追尾」「内接する円2を使った復帰」は現行仕様では使用しない。

数学的な反時計回りを正とする平面座標での表現例：
    φ = atan2(C.y-P.y, C.x-P.x) [deg]
    ψ = 現在の艦首角度 [deg]
    θ = 3秒ごとに選択して保持している75/90/105 [deg]
    s = +1（反時計回り）または-1（時計回り）
    ψ_target = φ - s×θ
    Δψ = DeltaAngle(ψ, ψ_target)
    if |Δψ| <= 10°: δ=0
    else: δ=Clamp(Δψ, -ωmax×dt, +ωmax×dt)
    ψ_next=ψ+δ
注：Unityの軸定義に合わせ、角度の正方向を統一すること。

============================================================
4. ステージデータによる指定・目標喪失【確定】
============================================================
・周回半径、周回中心の配置、護衛対象、攻撃対象など、AI個別パラメータはステージデータで指定する。
・丁字砲撃3,000 U、観測支援2,000 U、目標から固定中心まで5,000 Uはこれまでの基準値。ステージで調整可能。
・観測・支援射撃型の周回中心は固定座標として指定できる。
・目標喪失時の移行先AIをステージデータで指定可能。
・未指定の場合、砲台・空母型（停止）へ移行。
・明示指定により突撃軌道1型または2型へ移行可能。その場合の新たな攻撃対象の指定・取得方法はステージデータに紐づける。
・移行先目標も無効なときの安全側処理など、細部は実装時の例外処理として残す。

============================================================
5. 突撃軌道2型の旋回【確定】
============================================================
・前進全速固定。
・艦首方向と目標方位の角度差をαとする。
    |α| >= 90°：突撃軌道1型と同じ純粋追尾によって目標へ回頭
    |α| < 90° ：LOS角速度を用いた以下の制御
・LOS角速度 λdot（deg/s）の判定：
    λdot <= -5°/s   → 右へ最大旋回
    -5 < λdot < +5 → 直進
    λdot >= +5°/s  → 左へ最大旋回
・LOS角速度は自艦位置から目標への方位変化を時間で割って求める。
    λdot = DeltaAngle(λ_prev, λ_current)/dt
・「LOS角速度が0に近い」だけでは遠ざかるコースもあり得るため、角度差90°以上の純粋追尾復帰を組み込んだ。
・右左とLOS角速度の符号の対応はゲーム座標系で確認すること。

============================================================
6. 戦艦型AIの旋回【確定】
============================================================
・常に前進微速（最大速力×0.25）。
・艦首角ψと目標方位φの符号付き角度差 α=DeltaAngle(ψ, φ) を計算。
・目標艦首方向：ψ_target = φ - Sign(α)×90°
・目標方向との角度誤差が15°を超えたら旋回を開始。
・旋回開始後は角度誤差が8°以下になるまで旋回を継続（ヒステリシス）。
・旋回量は最大旋回速度と目標方向への到達制限を適用する。
・角度差の符号を毎フレームそのまま使用。左右の舷の選択を保持せず、0°や±180°への独自例外は加えない。
・回頭中も前進微速を維持。距離は制御しない。
注：Sign(0)の挙動は利用する関数に依存するため、実装時の関数仕様に従う。

============================================================
7. 共通射撃AI：目標ロック【確定】
============================================================
・艦全体に操艦上の優先対象を持てるが、兵装のロック対象は独立してよい。
・兵装種類ごとに対象カテゴリ配列を設定する。
    Ship（艦船）、Aircraft（艦載機）、Missile（ミサイル）
・各兵装マウントは、カテゴリに該当し、敵対し、生存し、射程内にいる候補から最寄りをロック。
・最寄り判定は兵装発射位置から対象の代表位置までの距離（距離の二乗で比較可）。
・一度ロックした対象は、他の敵が近づいても維持する。
・ロック解除条件は「撃破・消失・射程外」。
・射角外を理由にロック解除しない。射界の概念自体を設けない。
・ロック解除後は改めて最寄りの有効候補を選択する。
・艦の操艦対象と各兵装の射撃対象が一致する必要はない。

============================================================
8. 共通射撃AI：生存区画のランダム照準【確定】
============================================================
・目標が艦船の場合、射撃ごとに目標艦の生存区画から照準先を重み付きランダム抽選する。
・破壊済み区画は抽選から除外。
・区画カテゴリは5種：
    砲塔区画 / 標準装甲 / ERA / AEM / コア
・区画カテゴリ別の初期重みはすべて1。
    W=(1,1,1,1,1)
・重みの設定単位は「射撃する艦船」単位。各艦船に5種類の重みを持たせる。
・重みは「1区画ごと」に適用し、種類全体で合計1を配分するわけではない。
    P(i) = w_type(i) / Σ_j w_type(j)
  （和は抽選可能な生存区画について取る。）
・各弾の照準準備開始時に次の区画を選び、発射後は次の弾で再抽選。
・発射準備中に選択区画が破壊された場合は生存区画から再抽選。
・コアが生存艦に最低1区画残る前提。コアHPが0になれば艦は撃破扱い。
・艦載機やミサイルなど区画を持たない対象は、代表座標を照準点に使用する案。

============================================================
9. 共通射撃AI：一次偏差射撃【確定】
============================================================
・選択区画の現在位置、対象艦の並進速度、発射元艦の並進速度、兵装の弾速を用いる。
・対象区画自身の艦体旋回による追加速度は計算しない。
・弾体は発射元艦の速度を継承する。

記号：
    P  : 発射位置（世界座標）
    T  : 選択区画の現在位置（世界座標）
    r  : T-P
    Vs : 発射元艦の並進速度
    Vt : 目標艦の並進速度
    v  : Vt-Vs（相対速度）
    s  : 弾体の発射方向に沿った固有弾速（正）
    τ  : 会合時間

会合条件：
    |r + v×τ| = s×τ

二次方程式：
    (v・v - s²)τ² + 2(r・v)τ + r・r = 0

・最小の正の実数解τを採用。
・正の解が存在する場合の射撃方向：
    u = Normalize(r + v×τ)
・弾体の初速度（世界座標）：
    Vbullet = Vs + s×u
・会合点が存在しない場合は、目標区画の「現在位置」へ直接照準する：
    u = Normalize(T-P)
    Vbullet = Vs + s×u
・発射元速度を加えた結果、世界座標での弾体の速さが固有弾速sと異なる場合がある。
・本式は定速・直進する弾体を対象とする基本照準式。誘導弾・特殊兵装は後日個別定義。

============================================================
10. 共通射撃AI：射撃許可【確定】
============================================================
・兵装射程の判定には、対象の「現在位置」を使用する。予測会合点では判定しない。
    |Ptarget - Pweapon| <= Rweapon
・射界の概念なし（砲塔旋回時間や照準角度誤差を射撃条件に含めない）。
・砲塔の回頭・追従にかかる時間は考慮せず、計算した方向へ即座に発射できる。
・障害物・遮蔽物による射撃禁止判定なし。
・正の会合時間が存在しない場合も、現在位置への直接照準で射撃可能。
・装填／クールダウン、弾薬・エネルギーなど兵装本来の発射条件は満たす必要がある。
・実際に弾が障害物や味方艦と衝突する物理判定は、発射許可で遮蔽を考慮しないこととは別問題。

============================================================
11. 共通射撃AI：処理手順【確定方針】
============================================================
(1) 現在のロック対象が生存し、存在し、射程内にいるか確認。
(2) 無効ならロック解除し、攻撃対象カテゴリに該当する射程内の最寄りを再取得。
(3) 次弾の照準準備時に、対象艦の生存区画を区画種別の重みで抽選。
(4) 選択区画が発射前に破壊されていたら再抽選。
(5) 発射元・目標の並進速度と固有弾速から偏差射撃方向を計算。
(6) 有効な会合時間がなければ現在位置への直接照準へ切替。
(7) ロックと射程、装填、弾薬・エネルギー等を確認し、砲塔旋回待ちなく発射。
(8) 発射された弾体は発射時の方向・速度で飛翔。次弾は区画から再抽選。

============================================================
12. 今後別途定義する事項
============================================================
・実弾砲、レールガン、装薬砲、CIWS、魚雷、ミサイル、誘導砲弾、光学兵器、艦載機、端末砲台などの固有射撃・誘導・迎撃ルール。
・誘導弾のロック・発射後の目標追跡など、共通の定速直進弾体の式をそのまま使わない処理。
・周回中心や護衛対象の消失時に、新規指定先も無効だった場合の細かな例外処理。
・兵装に対し正の弾速が設定されていない等の不正データ対処。
・同距離の候補が複数ある場合のタイブレーク等、実装上の細部。

【重要な区別】
・射撃AIの「艦船ロック」は各兵装ごと。ロックは撃破・消失・射程外で解除する。
・「区画照準」は同じロック艦船の内部で発射ごとに再抽選する。
・「会合点」は照準方向の計算に用いるが、射程判定は対象の現在位置で行う。
・操艦AIの最大旋回速度と、射撃AIが砲塔の旋回を考慮しないことは別の仕様。
