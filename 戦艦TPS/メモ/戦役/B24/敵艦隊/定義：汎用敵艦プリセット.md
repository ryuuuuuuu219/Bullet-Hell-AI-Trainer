# 汎用敵艦プリセット

作成：2026-11-20。依頼に基づく15種の初期設計値。A・B・Cは同格のバリアントであり、上位互換・強化段階ではない。数値バランスと生成形状はUnity未検証。

## 共通規則

- 同じ艦種内ではコアHPを共通にし、武装配分・装甲・機動性能で差をつける。
- 表の兵装数は砲塔区画数。0は搭載なしを明示する。目安区画数は全兵装数＋Basic・ERA・AEMの区画数とし、コア分の+1は加えない。
- 全種の砲塔区画HPはコアHPの20%。被弾後の現在HPではなく、建造時のコアHPから算出する。
- 装甲欄は種類別の区画数。装甲設定IDは、その艦の各装甲種類のHP設定IDと迎撃力・装甲厚設定IDの両方へ適用する。0区画の種類も同じIDで記録する。
- 通常の小口径砲・大口径砲は装薬砲。レールガン狙撃砲艇の大口径砲のみレールガン方式。機関砲・ミサイルの方式は変更しない。
- 兵装性能は既存のMVP兵装カタログを参照する。レールガン化による射程・弾速等の独自ボーナスは追加しない。「狙撃」は建造上の役割であり、AIや実効射程の追加仕様ではない。
- ShipType欄は本プリセット用の識別名。enumの数値IDは未割当。兵装カタログID・設備ID・砲方式保存フィールド・設備性能文字列全体の形式も既存の未決定事項を維持する。名前別の数値を先に定義し、IDを推測してint[7]へ詰めない。
- 配置座標・旗艦・主AI・代替AIはEnemyShipDataで別途指定する。プリセットに旗艦属性や配置を固定しない。

## 3. 共通設備性能

全設備標準搭載の既存方針を維持し、以下は性能値の指定。未指定は設備の非搭載や効果0を意味しない。

|---|---|
| 発砲遅延装置 | 0.0000 |
| 装填装置 | 0.0000 |
| カタパルト | 既存仕様でもMVP値未指定のため未指定 |
| レーダー | 1.0000 |
| 電磁バリア | 既存の共通効果式を参照。個体性能値は未指定 |
| バウスラスター | 第2節のω_0 |
| スラスター | 第2節のV_0 |
| ジェネレーター | 速力補正1.0000、旋回補正1.0000 |
| 耐火素材の装甲 | 熱量加算軽減率0.0000 |
| ビームコーティング | EM加算軽減率0.0000 |

## 4. バリアントの狙い

| 艦種プリセット | 違い |
|---|---|
| コルベットA | 小口径砲と機関砲の均衡型 |
| コルベットB | 機関砲を減らして小口径砲と装甲を増加 |
| 高速砲艇A | 大口径砲を軸に直線速力を確保 |
| 高速砲艇B | 大口径砲と装甲を増やし機動力を交換 |
| ミサイル艇A | 標準的なミサイル搭載型 |
| ミサイル艇B | 砲と装甲を削り発射基数を増加 |
| ミサイル艇C | ミサイルを減らし近距離火力と生存性を確保 |
| レールガン狙撃砲艇A | 大口径レールガン2基とAEM装甲 |
| レールガン狙撃砲艇B | 砲数を増やし装甲と機動力を削減 |
| 重砲艇A | 重砲と装甲の均衡型 |
| 重砲艇B | 主砲集中型、近距離火力と防御を交換 |
| 重砲艇C | 主砲を減らして装甲と補助砲を増加 |
| 重コルベットA | 砲撃と近距離火力の均衡型 |
| 重コルベットB | 砲火力の一部をミサイルへ転換 |
| 重コルベットC | 小口径砲と装甲を増やした持久型 |

同格という設計意図を持つ初期値であり、同等の勝率を保証するものではない。各艦種内の比較では同じ敵・距離・AI条件で火力、生存時間、機動性を確認する。
