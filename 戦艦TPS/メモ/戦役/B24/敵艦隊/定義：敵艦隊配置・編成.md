# Project AYBS — 敵艦隊配置・編成の定義

作成：2026-11-20。

恒星系マップ上にどの敵艦隊を配置し、その艦隊との戦闘でどの艦をどこに生成するかを記入するメモ。2026-11-20の配置・装備指定を以下に反映。空欄は未決定を表し、0・艦なし・条件なしを意味しない。

本書の識別名・表の構成は記入用の整理であり、保存形式・IDの型・採番規則を確定するものではない。共通処理は参照元の仕様に従う。

## 1. 定義の対応

```text
恒星系マップ上の艦隊配置
  ├─ 所属・行動種別・拠点・初期位置または軌道
  ├─ 接敵時に使用するステージ
  └─ 使用する編成
       └─ 各艦の建造データ・戦闘内配置・旗艦指定・操艦AI
```

| 配置の種類 | 座標・意味 | 既存の方針 |
|---|---|---|
| 恒星系マップ上の配置 | 恒星系内での艦隊の位置・軌道 | マップ座標はdouble精度。表示用floatと区別する |
| 艦隊内の配置 | 戦闘シーン内での各艦の配置。距離はU | 道中戦闘の相対座標は編成データに固定し、マップの接近方向で回転させない |
| 編成の配置基準点 | 相対配置を戦闘領域内へ置く基準 | 基準点の決定方法とEnemyShipData.positionへの変換は未決定 |

マップ座標と戦闘座標は別に記入する。マップ100 U＝1 AUは候補であり、確定した換算率として扱わない。マップの基準時刻・軌道長半径の保存単位も未決定。

## 4. 撤退・再接敵で変化する編成

初期配置・初期編成と、戦闘結果による現在位置・残存艦・損傷状態は区別して管理する。以下の対応先を記入する。

| 項目 | 設定値 |
|---|---|
| ステージの撤退割合閾値（0～1） | |
| ステージの残存旗艦数閾値（整数） | |
| 戦闘内の撤退方向 | |
| 退避先候補となる敵拠点の参照 | |
| 拠点と合流先編成の対応 | |
| 撤退艦の元の建造データを識別する方法 | |
| 現在位置・残存艦・損傷の保存形式 | |

確定済みの引継ぎは次のとおり。

- 撤退艦は攻撃対象殲滅後、最寄りの他の敵拠点へ0.1 AU/日で移動する。対象の撤退による消失も殲滅に含む。
- 接敵判定の再開前に撤退敵艦隊を0.3 AU先行移動させる。全体時計は進めず、撤退艦隊位置から半径0.3 AU以内に撤退先拠点があれば即時合流する。
- 途中で再接敵した場合は撤退艦一覧で敵編成を上書きする。拠点到達後の接敵では合流先の艦隊へ追加して生成する。
- 保存する損傷はコアHP割合。生成後、コアを含む全区画のHPに乗算する。
- 合流時の座標重複はX座標を50 Uずつ、最大5回ずらす。解消しなければエラーとする。

撤退開始の判定・戦闘内の離脱処理はステージシーンデータ設計を参照する。

## 5. 記入・確定が必要な項目

個別艦隊の配置表・編成表を埋めるほか、次の共通事項が未決定のまま残る。

| 項目 | 決定内容 |
|---|---|
| 艦隊・編成・艦・拠点の識別子と保存形式 | |
| マップ座標の保存単位・基準時刻 | |
| 防衛艦隊の軌道項目の整合規則 | |
| 編成の基準点・相対座標から初期座標への変換 | |
| 主戦闘の配置方向・敵艦の初期方向 | |
| 保存された対象参照からGameObject配列を生成する方法 | |
| 攻略済みによる無効化の参照先拠点 | 防衛・攻撃部隊ごとに記入。共通規則は下記参照 |
| 同一ソーティー内の撃破状況 | ソーティー終了まで保持し、終了時にリセット。攻略済み拠点による恒久無効化は維持 |
| 撤退艦の先行移動時の時計・拠点到達処理 | 時計を進めない。半径0.3 AU以内に撤退先拠点があれば即時合流 |
