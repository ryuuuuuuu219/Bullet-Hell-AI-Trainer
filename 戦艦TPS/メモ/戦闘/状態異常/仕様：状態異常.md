# Project AYBS — 状態異常（火災・電磁障害）

作成：2026-11-18／更新：2026-11-19

## 1. 位置づけと用語

状態異常の詳細を本書で管理する。11月19日の指定を既存記述より優先する。設計メモの更新であり、コードへの実装・動作確認を意味しない。

- **電磁障害**：EM蓄積によって発動する状態異常の名称。属性付与量は引き続きEM付与量と呼ぶ。
- **熱量／EM付与量**：飛翔体が持つ、火災／電磁障害の蓄積へ加える値。
- **対コア属性付与倍率**：飛翔体が持つ、コアへ属性を付与するときの倍率。HPダメージ倍率とは区別する。
- **蓄積値**：艦のコアで保持する火災・電磁障害それぞれの値。単位はポイント（P）。両者を合算しない。
- **蓄積加算量の軽減率**：対象艦の施設によって、被弾ごとに蓄積値へ加える熱量・EMの量を減らす率。状態異常の発動前・発動中とも適用する。既存の蓄積値を減らす効果ではない。
- **時間減衰**：保持している蓄積値が毎秒5P減ること。付与時の減衰率とは別。
- **回復**：蓄積値が0Pになり、状態異常から回復すること。
- **施設**：耐火素材の装甲、ビームコーティング、火薬搭載量、絶縁層は正式設備。仕様・MVP予定値は「[仕様：施設設計.md](../../建造/設備/仕様：施設設計.md)」へ集約する。

## 2. 属性付与と施設

### 2.1 飛翔体が持つ値

飛翔体は熱量・EM付与量・対コア属性付与倍率を持つ。対象艦の施設による減衰を適用してから、コアの蓄積値へ加える。区画ごとに火災状態を保持しない。

減衰率を実数（確定値域0～0.99）で表す場合、通常の付与量Aに対する減衰後の値は `A × (1 − 減衰率)`。コアへの付与では対コア属性付与倍率を用いる。コア区画へのダメージに伴う属性付与量には対コア属性付与倍率を適用する。HPダメージにはこの倍率を掛けない。

区画（コアを含む）へのダメージごとに属性を蓄積する。複数区画への貫通・爆風も、各区画のダメージを付与単位とする。区画を経由するごとの付与量の減衰は行わない。施設による蓄積加算量の軽減とは区別する。付与先の状態はコアで一元管理する。

### 2.2 MVPの施設減衰率

| 対象 | 熱量減衰率 | EM減衰率 |
|---|---:|---:|
| プレイヤー | 0% | 0% |
| 敵艦 | 0% | 0% |

### 2.3 MVPの飛翔体属性（プレイヤー・敵艦共通）

| 兵装 | 熱量 | EM付与量 | 対コア属性付与倍率 |
|---|---:|---:|---:|
| 小口径砲 | 5 | 0 | 1.1 |
| 大口径主砲 | 12 | 0 | 1.2 |
| 機関砲 | 0.2 | 0 | 1 |
| 対艦ミサイル | 10 | 1 | 1.2 |

### 2.4 状態異常に関係する正式設備

| 目的 | 正式設備 |
|---|---|
| 熱量・EMの蓄積加算量を軽減 | 耐火素材の装甲、ビームコーティング |
| 蓄積値上限の補正 | 火薬搭載量、絶縁層 |

熱量・EM付与量に関する施設補正は、次の共通範囲を用いる。

| 項目 | 共通仕様 |
|---|---|
| 蓄積加算量の軽減率 | 0～0.99（0～99%） |
| 蓄積値上限の補正 | −49～0P（指定の「−0～−49」） |
| 補正後の蓄積値上限 | `150P + 上限補正`（101～150P） |
| 保持精度 | 小数第4位（0.0001刻み）まで保持。熱量・EM付与量の両方に共通 |
| 表示精度 | ％表示で小数第2位まで表示（例：減衰率0.1234 → 12.34%）。保持精度と区別する |

艦全体のMVP減衰率は本書第2.2節、正式設備ごとの値・上限補正は「[仕様：施設設計.md](../../建造/設備/仕様：施設設計.md)」を参照する。施設の配置・搭載・保存仕様は「[シーン設計1：艦設計システム.txt](../../建造/シーン設計1：艦設計システム.txt)」に従う（建造入力と設備配置、第7節「設備の同時搭載制限」、第8節「機関性能・保存」）。

## 3. 発動・維持・回復【11月19日決定】

| 項目 | 仕様 |
|---|---|
| 管理単位 | 火災・電磁障害ともコアで一元管理 |
| 発動 | 蓄積値が100Pを上回ると発動（100Pちょうどは含まない） |
| 時間減衰 | 火災・電磁障害とも毎秒5P |
| 回復 | 0Pで回復。発動後に100P以下へ下がっただけでは回復しない |
| 発動時の消費 | 0P。蓄積値を保持する |
| 発動中の上書き | あり。一律等倍 |
| 蓄積値上限 | 基本150P。施設補正は−49～0P、補正後101～150P |

上書き時の効果倍率を重ね掛けして強化する扱いにはしない。「等倍」に従う。上書きでは判定間隔を変更せず、進行中の判定タイマーもリセットしない。火災は従来の2秒間隔の判定を継続する。
