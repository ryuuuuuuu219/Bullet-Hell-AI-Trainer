# 戦闘内の惑星引力

元資料：[一覧・関連節](仕様：ステージシーンデータ設計.md)。以下の節番号と「本書」は元資料の構成を指す。

### 戦闘内の一定引力

- ステージデータで生成した惑星中心へ向けて、艦と実弾砲の砲弾へ一定の引力を作用させる。
- 距離による減衰は行わず、引力の大きさをステージデータのスカラーで定義する。
- ステージ指定スカラーの単位はU/s。毎フレーム、`引力の速度ベクトル = ステージ指定スカラー × normalize(惑星中心 − 対象位置)` を通常移動の速度ベクトルへ合成する（11月21日決定）。
- `合成速度[U/s] = 通常移動速度 + 引力の速度ベクトル`、`フレームの移動量[U] = 合成速度 × deltaTime[秒]`。引力を加速度として速度へ累積加算せず、そのフレームの速度寄与として扱う。U/sの値をそのまま1フレームの移動距離にはしない。
- スカラーの具体値はステージごとに設定する。惑星中心で方向が未定義になる場合の扱いは未決定。
- ミサイル・ビームへの適用は今回指定していない。マップ側の重力数値積分は引き続き対象外。
