==================================================
1. 共通の艦船運動仕様【確定】
==================================================
・艦首方向への前進、艦尾方向への微速後進が可能。横移動は行わない。
・加速度、旋回加速度、慣性モーメントは扱わない。速度の切替は瞬時。
・速度指示は4段階：
    後進微速 = -0.25 × 最大速力
    停止     =  0
    前進微速 = +0.25 × 最大速力
    前進全速 = +1.00 × 最大速力
・最大速力、最大旋回速度は建造時の性能計算で確定し、戦闘中の区画破壊で再計算しない。
・最大旋回速度は最終的に5～135 deg/sの範囲に制限される。
・周回型AI（丁字砲撃／観測・支援射撃／護衛）は、旋回中・半径補正中も常に前進全速。
・「周回型は全速」の決定を、停止型の砲台・空母や低速の戦艦型へ無条件に拡張しない。

(1) 突撃軌道1型

3. 周回型AI：共通の誘導方針【確定】
==================================================
・自艦から周回中心へ向かう方向を基準に、中心が艦首から横方向に見える姿勢を保とうとする。
・距離が適正なら90°、近すぎれば105°、遠すぎれば75°を目標角度とする。
・角度は「艦首方向」と「自艦→周回中心ベクトル」がなす角度。
・105°では外向き、75°では内向き、90°では接線方向の速度成分を生む。
・周回中心や周回半径へ強制的に座標補正はせず、艦の最大旋回速度の範囲内で操舵する。
・周回方向（時計／反時計）は開始時に艦首から旋回量が少ない側を選択し、通常は維持する。

[座標・記号]
    P       : 自艦位置
    C(t)    : 周回中心の現在位置
    R       : 指定周回半径（R > 0）
    d       : |C(t) - P|
    φ       : atan2(C.y - P.y, C.x - P.x) [deg]
    ψ       : 現在の艦首方位 [deg]
    s       : 周回方向符号（+1=反時計回り、-1=時計回り）
    θ       : 距離帯から選択した目標角度 [deg]
    ωmax    : 艦船の最大旋回速度 [deg/s]
    Δt      : フレーム経過時間 [s]

[距離別の目標角度]【確定】
    d < 0.92R            → θ = 105°（外向き補正）
    0.92R <= d <= 1.08R → θ =  90°（周回維持）
    d > 1.08R            → θ =  75°（内向き補正）

[各角度の旋回不感帯]【確定】
    θ=105° → 95°～115°
    θ= 90° → 80°～100°
    θ= 75° → 65°～ 85°
    目標方位との符号付き最短角度差の絶対値が10°以内なら旋回しない。
    10°超なら目標方位に向けて旋回する。

[各AIの具体的な距離帯]
    丁字砲撃型 R=3,000 U
        d<2,760 U           →105°
        2,760～3,240 U      → 90°
        d>3,240 U           → 75°
    観測・支援射撃型 R=2,000 U
        d<1,840 U           →105°
        1,840～2,160 U      → 90°
        d>2,160 U           → 75°
    護衛型 R=未決定
        d<0.92R             →105°
        0.92R～1.08R        → 90°
        d>1.08R             → 75°

4. 周回方向の決定と目標方位【確定仕様の具体化】
==================================================
初期化時に、現在の中心方向φと現在艦首ψから、左右どちらの目標方位への旋回量が少ないか比較する。

    ψ_CCW = φ - θ
    ψ_CW  = φ + θ

    abs(DeltaAngle(ψ, ψ_CCW)) <= abs(DeltaAngle(ψ, ψ_CW))
       なら s=+1（反時計回り）
       それ以外なら s=-1（時計回り）

同角度のときは反時計回りを選ぶ処理を暫定とする。
選択した周回方向sは、通常、毎フレーム再選択しない。

目標艦首方位：
    ψ_target(t) = φ(t) - s × θ_hold

※θ_holdは後述の3秒更新で保持する75°／90°／105°の値。
※周回中心が移動した場合もφ(t)は毎フレーム再計算する。
※ここに示す符号は、数学的な角度が反時計回り正のXY座標を前提とする。Unityの実際の座標軸に応じて符号・角度変換を統一する。

==================================================
5. 旋回量の決定【方式Cを確定】
==================================================
「最大旋回速度＋目標角度への到達制限」を採用する。
旋回加速度や比例制御係数は導入しない。

    Δψ = DeltaAngle(ψ, ψ_target)

    if abs(Δψ) <= 10°:
        δ = 0
    else:
        δ = Clamp(Δψ, -ωmax×Δt, +ωmax×Δt)

    ψ_next = ψ + δ

・目標方位が固定なら、1フレームで目標を越えて旋回しない。
・±10°の範囲に入ったら旋回を停止するため、必ず目標方位へ完全一致させる処理ではない。
・前進全速は旋回の有無と独立して維持する。

==================================================
6. 目標角度の更新周期【3秒で確定】
==================================================
距離に基づく「75°／90°／105°の選択」を3秒ごとに限定する。
一方、周回中心への方位の計算と実際の旋回は毎フレーム行う。

[処理周期]
    周回中心の現在位置の取得    : 毎フレーム
    周回中心への方位φの計算    : 毎フレーム
    距離帯の判定              : 3秒ごと
    θ_holdの更新              : 3秒ごと
    ψ_targetの計算            : 毎フレーム
    ±10°の旋回停止判定        : 毎フレーム
    旋回角度δの計算・適用     : 毎フレーム
    前進全速での位置更新      : 毎フレーム

[3秒ごとの距離帯判定]
    if d < 0.92R:          θ_hold = 105°
    else if d <= 1.08R:   θ_hold =  90°
    else:                 θ_hold =  75°

・周回制御の開始直後や周回中心の切替直後は、3秒を待たずに初期θ_holdを計算する。
・一度設定したθ_holdは次の更新時刻まで維持する。
・移動する目標への方位φ(t)自体は3秒間固定しない。
・距離帯が閾値付近を行き来した際の目標角度の頻繁な切替を抑える目的。
・最大速力が高い艦では、3秒の保持により半径補正が遅れる可能性を許容する。

7. 移動する周回中心への追従【方式Aを確定】
==================================================
・周回中心は「現在位置」のみ使用する。
・目標速度の合成、未来位置の予測は行わない。
・丁字砲撃型では攻撃対象の現在位置、護衛型では護衛対象の現在位置を毎フレーム参照する。
・観測・支援射撃型では一度配置した固定中心を参照する。
・中心が高速移動した場合に指定半径を維持しきれなくても、強制的な位置補正はしない。

12. 突撃軌道2型：LOS角速度制御【2026-11-14確定】
==================================================
【目的】
・最終的に攻撃対象との衝突コースへ入ることを狙う。
・単なる「目標への方位追尾」ではなく、目標への視線方向（LOS）の角速度を抑える操艦を行う。
・厳密な比例航法の式を採用するわけではない。ゲーム内で「比例航法」と表示する予定はない。
・加速度・慣性なし、艦首方向へ前進全速は他の突撃型と同様。

【座標・記号】
    P    : 自艦位置
    T    : 攻撃対象位置
    ψ    : 自艦の艦首方位 [deg]
    λ    : atan2(T.y-P.y, T.x-P.x) ＝ LOS方位 [deg]
    α    : DeltaAngle(ψ, λ) ＝ 艦首方向とLOS方位の符号付き差 [deg]
    λdot : LOS角速度 [deg/s]
    ωmax : 自艦の最大旋回速度 [deg/s]

【旋回モードの切替】
    abs(α) >= 90° : 突撃軌道1型（純粋追尾）と同じ回頭ロジックを使う。
    abs(α) <  90° : LOS角速度による旋回制御を使う。
    ※90°ちょうどは純粋追尾側に含む。
    ※純粋追尾中も前進全速。目標方向へ回頭するが、旋回速度上限ωmaxを守る。
    ※毎フレーム切替判定する案。90°境界での振動対策は未決定。

【LOS角速度からの旋回指示】
    λdot <= -5 deg/s  : 右へ最大旋回
    -5 < λdot < +5   : 直進（旋回しない）
    λdot >= +5 deg/s : 左へ最大旋回
    ※右旋回＝時計回り、左旋回＝反時計回りとする数学XY座標系の仮置き。
    ※左右の符号が実際にLOS角速度を抑える方向になるかは、Unityの座標・回転系と
      自艦の運動によるフィードバックを踏まえて実機検証する（現時点では仕様の指示方向を維持）。

【LOS角速度の計算法】
    λdot = DeltaAngle(λ_prev, λ_current) / Δt
    または
    r = T - P,  v_rel = V_target - V_ship
    λdot = (r.x * v_rel.y - r.y * v_rel.x) / |r|^2 * (180 / π)
    ※2式のどちらを用いるかは未決定。
    ※距離が極小のときの除算防止、角度差の折り返し、最初のフレームの初期化を要する。

【目標とする到達状態】
    ・LOS角速度がほぼ0で、かつ両者が接近している状態を目指す。
    ・LOS角速度≈0だけでは、遠ざかる場合や並走の場合もあるため衝突コースを保証しない。
    ・abs(α)>=90°での純粋追尾移行により、目標が後方半球にある場合は回頭する。
    ・全速・有限の最大旋回速度・±5 deg/sの不感帯があるため、衝突を必ず保証する仕様ではない。

15.戦艦型AI
- 移動速度： 常に前進微速（最大速力の25%）
- 目標方向： 目標方位から、現在の角度差の符号に応じて±90°回転した方向

- 旋回終了： 角度差が8°以下になったとき
- 旋回速度： 最大旋回速度を上限とする到達制限制御
- 左右の選択： 毎フレーム判定し、以前の選択は保持しない
- 距離制御： なし
