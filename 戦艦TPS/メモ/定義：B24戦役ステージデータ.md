作成：2026-11-20。B24戦役の個別ステージ値を記入する台帳。共通構造は「仕様：ステージシーンデータ設計.md」を参照する。空欄は未決定であり、敵なし・報酬なし・攻略不能などを意味しない。

## 1. 確定している戦役条件

| 項目 | 定義 |
|---|---|
| MVP範囲 | B24恒星系内 |
| 天体構成 | 惑星7個＋彗星1個 |
| 主人公拠点 | 第4惑星L2。選択可能、出撃先にはしない。建造ボタンを表示 |
| 出撃元 | 毎回、主人公拠点 |
| 選択対象 | 惑星と各天体のL1～L5。選択可能と戦闘ステージの存在は区別する |
| 攻略先の初期選択 | 全攻略先を初期選択可能とする方針 |
| 彗星L点 | L1～L5を設定するが拠点を配置しない |
| 彗星自体の攻略対象化 | |
| 道中戦闘 | 敵部隊との接敵、5,000×5,000 U |
| 主戦闘 | 拠点・旗艦との戦闘、60,000×60,000 U |
| 到着判定半径 | 0.005ゲーム内AU |

## 4. 報酬の共通条件

敵撃破時0.2%、成立後は兵装／設備を各1/2。戦艦はコア撃破時のみ。ステージクリア時の戦術ドロップは15%。詳細は「仕様：1115確定事項まとめ.md」。個別のドロップ対象・戦術内容・重複処理は空欄のまま扱う。
