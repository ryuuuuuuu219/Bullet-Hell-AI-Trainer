### プレイヤー艦の建造保存・生成

建造シーンでプレイヤーの次の項目を保存する。ステージ開始処理は保存済みデータを読み出してプレイヤー艦を生成し、PlayerSpawnDataの座標・向きを適用する。初速は0。

| フィールド | 型 |
|---|---|
| weaponIDs | int[7] |
| weaponCounts | int[7] |
| turretHP | int |
| armorSettings_Basic | ArmorSetting |
| armorSettings_ERA | ArmorSetting |
| armorSettings_AEM | ArmorSetting |
| coreHPSettingID | int |
| seed | int |
| EquipmentPerformanceValues | string |
| equippedEquipmentInstanceIDs（名称案） | 設備個体IDの配列。要素型は未決定 |

装備中IDは設備種別IDとは別の、所持する設備個体への参照として保存する。兵装はweaponIDsでカタログIDを、weaponCountsで数量を保存する。設備個体IDの採番・型・性能保存値との照合方法は未決定。

入力不備はエラーとする。既存の惑星侵入禁止領域と敵艦初期配置の重複検出と同じ方針で検証し、不備を黙って補完しない。保存ファイルの場所・読み書き方式は別途定義する。

### 建造中データの保存条件

- 目安区画数・装甲区画数・武装区画数はプレイヤーが指定する。
- `目安区画数 == 装甲区画数 + 砲塔区画数` を恒星系マップへの遷移・保存条件とする。ここで砲塔区画数は武装区画数を指す。この式にコア用の+1は加えない。
- 不一致なら設計中データを保存せず、以前の保存済み設計を維持する。
- 一致し、入力検証を通過した状態で「恒星系マップへ戻る」を押した際にのみ設計を保存して遷移する。不一致では戻れない。
- 条件の成立／不成立が切り替わった時にボタンの状態を更新する。不成立時は半透明・操作不可、成立時は通常表示・操作可能とする。半透明時の具体的な透明度は未決定。
- 保存済み設計と編集中データを分離し、戦闘で使用するのは保存済み設計とする。
- 目安区画数はプレイヤーが指定する生成の目安とし、実際に生成された区画数との一致は判定しない。実生成区画数の過不足を理由とする再生成・エラー・保存拒否は行わず、実生成区画数は性能欄に表示する。入力値同士の保存条件とは区別する。
