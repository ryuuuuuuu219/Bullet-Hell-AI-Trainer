# Project AYBS — 敵艦隊配置・編成の定義

作成：2026-11-20。

恒星系マップ上にどの敵艦隊を配置し、その艦隊との戦闘でどの艦をどこに生成するかを記入するメモ。個別艦隊の数値・構成は未設定。空欄は未決定を表し、0・艦なし・条件なしを意味しない。

本書の識別名・表の構成は記入用の整理であり、保存形式・IDの型・採番規則を確定するものではない。共通処理は参照元の仕様に従う。

## 1. 定義の対応

```text
恒星系マップ上の艦隊配置
  ├─ 所属・行動種別・拠点・初期位置または軌道
  ├─ 接敵時に使用するステージ
  └─ 使用する編成
       └─ 各艦の建造データ・戦闘内配置・旗艦指定・操艦AI
```

| 配置の種類 | 座標・意味 | 既存の方針 |
|---|---|---|
| 恒星系マップ上の配置 | 恒星系内での艦隊の位置・軌道 | マップ座標はdouble精度。表示用floatと区別する |
| 艦隊内の配置 | 戦闘シーン内での各艦の配置。距離はU | 道中戦闘の相対座標は編成データに固定し、マップの接近方向で回転させない |
| 編成の配置基準点 | 相対配置を戦闘領域内へ置く基準 | 基準点の決定方法とEnemyShipData.positionへの変換は未決定 |

マップ座標と戦闘座標は別に記入する。マップ100 U＝1 AUは候補であり、確定した換算率として扱わない。マップの基準時刻・軌道長半径の保存単位も未決定。

## 2. 恒星系マップの艦隊配置一覧

配置する艦隊ごとに1行を追加する。同じ編成を使用する艦隊でも、マップ上で別々に行動する場合は別行で記入する。

| 艦隊識別名 | 表示名 | 所属 | 行動種別 | 所属・出撃元拠点 | マップ配置詳細の参照 | 編成の参照 | 接敵ステージの参照 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

行動種別は哨戒艦隊・防衛艦隊・攻撃艦隊。戦闘内の操艦AI種別とは別に指定する。具体的な配置数、所属、拠点と艦隊の対応は空欄のまま記入待ちとする。

|---|---|---|---|

### 3.2 編成詳細（編成ごとに複製して記入）

| 項目 | 設定値 |
|---|---|
| 編成識別名 | |
| 戦闘領域内の配置基準点X・Y（U） | |
| 基準点の決定方法 | |
| 主戦闘での配置方向の扱い | |

艦1隻につき1行を記入する。相対座標の基準と、ステージデータの初期座標への変換方法が未確定の間は、両者を同じ値とみなさない。

| 艦の識別名 | 建造データの参照 | 相対X（U） | 相対Y（U） | 初期の向き（度） | 旗艦か | 主AI | 代替AI | AI個別設定の参照 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

- 旗艦は複数指定できる。
- 敵艦の初速は0 U/s。生成後に操艦AIを開始する。
- 道中戦闘の編成はマップ上の接近方向で回転させない。敵艦の初期の向きは別途記入する。
- 道中戦闘のプレイヤーは右向き、初速0。プレイヤーの配置はステージ側で指定する。
- 通常の初期配置での重複・入力不備はエラーとする。撤退艦の合流時に限る座標補正と混同しない。

| 項目 | 設定値 | 扱い |
|---|---|---|
| ステージの攻撃対象 | | 戦闘中はGameObject配列 |

## 4. 撤退・再接敵で変化する編成

初期配置・初期編成と、戦闘結果による現在位置・残存艦・損傷状態は区別して管理する。以下の対応先を記入する。

| 項目 | 設定値 |
|---|---|
| ステージの撤退割合閾値（0～1） | |
| ステージの残存旗艦数閾値（整数） | |
| 戦闘内の撤退方向 | |
| 退避先候補となる敵拠点の参照 | |
| 拠点と合流先編成の対応 | |
| 撤退艦の元の建造データを識別する方法 | |
| 現在位置・残存艦・損傷の保存形式 | |

確定済みの引継ぎは次のとおり。

- 撤退艦は攻撃対象殲滅後、最寄りの他の敵拠点へ0.1 AU/日で移動する。対象の撤退による消失も殲滅に含む。
- 接敵判定の再開前に撤退敵艦隊を0.3 AU先行移動させる。全体時計の扱いと、この移動で拠点へ到達した場合の処理は未決定。
- 途中で再接敵した場合は撤退艦一覧で敵編成を上書きする。拠点到達後の接敵では合流先の艦隊へ追加して生成する。
- 保存する損傷はコアHP割合。生成後、コアを含む全区画のHPに乗算する。
- 合流時の座標重複はX座標を50 Uずつ、最大5回ずらす。解消しなければエラーとする。

撤退開始の判定・戦闘内の離脱処理はステージシーンデータ設計を参照する。
