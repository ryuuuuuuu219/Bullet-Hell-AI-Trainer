# 弾幕×アクアリウム メモ案内

現行企画、種別仕様、共通システム、観測ログを分けて管理する。

## フォルダ

- `企画書/`：企画全体、ステージ構想、参照チャットの記録。
- `戦艦型動物/`：戦艦型動物の現行設計と、形状生成の検証記録。
- `草/`：草の現行実装仕様と、初期セル・オートマトン設計の記録。
- `草食動物/`：草食動物の現行実装仕様、生存戦術の設計検討、参考画像。
- `動物/`：複数栄養段階のMVP、種族設定、繁殖・昼夜、肉食動物、生存スコア。
- `経済/`：HP・炭素・SP、回復、ドロップの共通経済仕様。
- `ログ/`：Play Modeやモデル計算で得た観測記録。仕様書そのものではない。

現行仕様、設計案、過去記録、実際の動作確認は各文書の位置づけに従って区別する。
