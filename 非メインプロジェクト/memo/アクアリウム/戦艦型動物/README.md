- [タイリングテストシーン.md](タイリングテストシーン.md)：形状生成の操作、探索上限、検証記録。

形状生成は、探索上限で端部を形成できない場合を含めて完成扱い。2026-10-30時点でbattle0への生成マネージャー配置と、指定した艦種・目安区画数による形状スポーンまで実装済み。区画役割・HP・被弾・脱落、MVP砲塔、艦種別の移動・対象選択・逃走優先は設計確定済みだが、生態系への登録、移動、被弾、射撃を含む戦闘本体への組込みは未実装。
